01

ERMaster와 같은 형식

Relio에서 열고 저장한 .erm을 ERMaster에서도 엽니다. 팀에 ERMaster 사용자가 있어도 섞어 쓰고, 열고 저장한 것만으로는 파일에 차이가 생기지 않습니다.

기능

그리는 데서 끝나지 않습니다

검사하고, 찾고, 비교하고, 합치는 일까지 한 도구에서. 그림은 모두 실제 앱 화면이고, 모델은 소개용으로 꾸며낸 예제입니다.

Git과 함께

같은 파일을 둘이 고쳐도 모델 단위로 합칩니다

병합 충돌이나 바깥에서 바뀐 파일을 줄이 아니라 테이블·컬럼·필드 단위로 합칩니다. 양쪽이 각자 더한 것은 그대로 들어오고, 같은 칸을 다르게 고친 것만 고르면 됩니다. 결과는 늘 올바른 .erm입니다.

  • 두 모델 비교와 커밋 이력
  • 변경 SQL(ALTER) 만들기
  • relio merge를 Git merge driver로

설계 검사

그리는 동안 문제를 먼저 알려 줍니다

  • 참고는 규칙마다 한 줄로 접어서

찾기와 강조

초성만 쳐도 ‘주문’을 찾습니다
