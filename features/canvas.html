캔버스와 팔레트 ​

캔버스 읽는 법, 팔레트 도구, 선택·옮기기, 배치 메뉴, 보기 메뉴의 표시 설정, 확대·이동과 패널, 아웃라인을 설명합니다.

화면을 빠르게 다루는 방법만 보려면 빠른 시작의 화면 다루기를, 그리는 순서는 테이블·컬럼·관계 그리기를 보세요.

화면의 각 부분(메뉴·도구 모음·팔레트·아웃라인·상태 표시줄)과 "노드"라는 말은 기능 설명 › 화면 구성에 정리해 두었습니다.

캔버스 읽는 법 ​

테이블 상자 ​

  • 머리에 테이블 이름이 있고, 아래에 컬럼이 한 줄씩 나옵니다. 기본 키(PK) 컬럼은 위쪽에 따로 모이고 가는 선으로 나머지와 나뉩니다.
  • 컬럼 줄 왼쪽의 PK · FK 딱지는 기본 키(PK) · 외래 키(FK) 컬럼입니다. 둘 다이면 딱지가 둘 붙습니다.
  • 이름 오른쪽에 형식(예: varchar(100))이, 줄 끝에 작은 글자로 NN(NOT NULL) · UQ(UNIQUE)가 나옵니다.
  • 자동 증가(AUTO_INCREMENT) 컬럼은 이름 바로 뒤에 작은 원 안의 + 표시가 붙습니다. 마우스를 올리면 "자동 증가"가 보입니다.
  • 그룹 컬럼은 ≡ 그룹명 한 줄로 기울여 나옵니다. 보기 › 표기 수준 ▸ › 그룹 확장을 켜면 그룹 안 컬럼을 펼쳐 보입니다.
  • 뷰는 테이블과 같은 모양이고 머리 오른쪽에 VIEW가 붙습니다.
  • 컬럼이 하나도 없는 테이블에는 "더블클릭해 컬럼 추가" 안내가 흐리게 보입니다(그림 내보내기·인쇄에는 나오지 않음).
  • 빈 새 문서에는 캔버스 가운데에 "테이블 추가 (T)"와 첫 테이블을 만드는 방법이 흐리게 보이고, 노드를 하나 만들면 사라집니다.

관계선 끝 기호 ​

관계선은 부모(참조되는 테이블)와 자식(외래 키(FK)를 가진 테이블)을 잇습니다. 선 끝 기호는 관계 정보 창의 다중성을 보여 주고, 보기 › 표기법 ▸에서 IE·IDEF1X 중 고릅니다. 노트 연결선은 기호 없는 점선입니다.

  • 도구는 한 번 쓰면 선택 도구로 돌아갑니다. Shift를 누른 채 쓰면 같은 도구가 유지되어 여러 개를 이어 만들 수 있습니다. 손 도구는 늘 유지됩니다.
  • 관계 도구는 첫 테이블을 누른 뒤 두 번째 테이블을 누르거나, 첫 테이블에서 끌어 두 번째 테이블에서 놓습니다. 빈 곳을 누르거나 Esc를 누르면 취소합니다. 1:N 관계 도구로 같은 테이블을 두 번 누르면 재귀 관계가 됩니다.
  • 키보드로만 관계 만들기 — Tab으로 부모 테이블에 포커스를 옮기고 R로 관계 도구를 고른 뒤 Enter로 부모를 정합니다. 다시 Tab으로 자식 테이블에 포커스를 옮기고 Enter를 누르면 관계가 생깁니다.
  • 부모에 기본 키가 없으면 "참조할 컬럼이 없습니다 — 부모 테이블에 기본 키가 없습니다."라고 알립니다.
  • 새 테이블의 이름은 앱 언어를 따릅니다(한국어면 논리명 "새 테이블", 물리명 NEW_TABLE).

선택·옮기기 ​

  • 선택 — 클릭, Shift+클릭(또는 Ctrl+클릭)으로 더하거나 빼기, 빈 곳을 끌어 범위 선택. Esc로 선택을 해제합니다.
  • 옮기기 — 끌거나 방향키로 1칸, Shift+방향키로 10칸 옮깁니다. 끄는 동안 다른 노드의 경계·가운데에 맞춤 안내선이 보입니다.
  • 크기 — 테이블·뷰를 고르면 왼쪽·오른쪽 손잡이로 너비를 바꿉니다. 넓히기는 마음대로, 줄이기는 내용이 다 보이는 너비까지입니다. 높이는 늘 컬럼 수에 맞습니다. 노트·이미지·카테고리는 손잡이로 크기를 바꿉니다.
  • 이름 바로 고치기 — F2. 테이블은 물리명, 노트는 글을 그 자리에서 고칩니다. 다른 프로그램으로 넘어갔다 와도 칸이 닫히지 않고 이어 칠 수 있습니다.
  • 정보 창 — 더블클릭 또는 Enter. 정보 창
  • 포커스 옮기기 — Tab / Shift+Tab으로 다음·이전 노드.

캔버스에서 컬럼 다루기 ​

  • 테이블 안 컬럼을 누르면 그 컬럼을 고릅니다. 보기 › 컬럼 클릭 금지를 켜면 테이블만 골라집니다.
  • 고른 컬럼을 끌어 같은 테이블 안에서 순서를 바꾸고, 다른 테이블에 놓으면 그리로 옮깁니다. Ctrl을 누른 채 놓으면 옮기지 않고 복사합니다.
  • 다른 테이블이 참조하는 컬럼은 옮길 수 없습니다. FK 컬럼을 다른 테이블로 옮기면 관계를 다시 만들어 그 테이블이 자식이 됩니다.
  • 그룹 컬럼은 그룹 단위로 옮기고, 그룹을 고르고 Delete를 누르면 테이블에서 그룹을 뺍니다.
  • 아웃라인의 단어·그룹을 캔버스의 테이블에 끌어다 놓으면 컬럼(그룹)이 됩니다.

연결선 ​

  • 관계선을 끌면 꺾임점이 생기고, 꺾임점을 끌어 옮기고, 꺾임점을 더블클릭하면 지웁니다.
  • 관계선 끝을 끌어 같은 테이블 테두리의 다른 자리로 옮깁니다. 테이블 가운데쪽에 놓으면 자동 위치로 돌아갑니다.
  • 관계 이름은 선 위에 그리지 않습니다. 관계선을 고르면 이름이 도구 설명으로 보입니다.

확대·이동 ​

  • 확대·축소 — Ctrl+마우스 휠(마우스 위치 기준), Ctrl+= · Ctrl+- · Ctrl+0, 도구 모음의 배율 목록.
  • 화면 이동 — Space를 누른 채 끌기(놓으면 원래 도구로), 손 도구(H), 마우스 가운데 버튼 끌기, 터치패드 두 손가락 스크롤, 축소 미리보기의 사각형 끌기. 글을 치는 중에는 Space가 글자로 들어갑니다.
  • 배율이 40%보다 작으면 노드를 이름만 있는 간단한 상자로 그리고, 카테고리 이름을 크게 띄워 지도처럼 보이게 합니다. 이미지 내보내기·인쇄는 늘 원래 모양입니다.
  • 배율과 보던 위치는 문서에 저장됩니다.

패널과 시작 화면 ​

  • 오른쪽 패널(아웃라인·축소 미리보기)은 Ctrl+Alt+B, 아래 패널(문제 목록)은 Ctrl+J로 접고 폅니다. 문서 탭 줄 오른쪽 끝의 단추 둘과 보기 › 패널 ▸도 같습니다.
  • 캔버스 최대화 — 문서 탭을 더블클릭하거나 Ctrl+Shift+M을 누르면 두 패널을 한 번에 접고, 다시 하면 접기 전으로 돌아갑니다. 팔레트는 접지 않습니다.
  • 접은 상태는 다음에 켜도 그대로입니다.
  • 시작 화면 — 보기 › 시작 화면을 고르면 새로 만들기·열기·샘플·최근 파일이 있는 시작 화면이 나옵니다. 열린 문서는 닫히지 않고, 탭을 누르거나 Esc 또는 열린 문서로 돌아가기로 돌아갑니다. 시작 화면을 보는 동안은 문서 메뉴와 편집 단축키가 꺼집니다.

아웃라인 ​

  • 맨 위 이름으로 찾기 칸에 치면 목록을 걸러 봅니다.
  • 테이블·뷰를 누르면 그 아래로 컬럼(그룹 컬럼은 그룹 이름 한 줄)과, 테이블이면 인덱스가 펼쳐집니다.
  • 항목을 더블클릭하면 그 정보 창이 열립니다: 단어 → 단어 정보, 그룹 → 그룹 관리, 인덱스·시퀀스·트리거·테이블스페이스 → 각 정보 창, 테이블·뷰 → 캔버스에서 그 노드로 가서 선택하고 테이블(뷰) 정보 창을 엶, 컬럼 → 그 컬럼을 선택한 채 테이블 정보 창을 엶.
  • 단어·그룹은 캔버스의 테이블에 끌어다 놓아 컬럼으로 넣을 수 있습니다.
  • 오른쪽 클릭: 삭제, 그룹 관리, 트리거 추가 · 시퀀스 추가 · 인덱스 추가 · 테이블스페이스 추가(고른 종류에 맞는 것만), 개요 보기 모드(논리명 · 물리명 · 논리명+물리명), 정렬 기준(논리명 · 물리명).
  • 개수가 0인 줄은 흐리게 보이고 + 추가로 첫 항목을 바로 만듭니다. 시퀀스·테이블스페이스는 그 DB(버전)가 지원할 때만 추가할 수 있습니다.
