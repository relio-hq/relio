DDL ​

모델에서 DB에 실행할 SQL(DDL)을 만드는 DDL 내보내기 창의 항목과, DB 버전에 따른 문법 처리·경고를 설명합니다.

짧은 순서는 빠른 시작의 DDL 만들기·내보내기에 있습니다.

여는 곳 ​

  • 파일 › 내보내기 ▸ › DDL…
  • 캔버스 오른쪽 클릭 › 문서 ▸ › 내보내기 ▸ › DDL…
  • 명령줄 relio export ddl — 명령줄

지원 DB: PostgreSQL · MySQL · MariaDB · Oracle · SQL Server · DB2 · H2 · HSQLDB · SQLite · Informix · MS Access · 표준 SQL.

창 위쪽: 대상과 출력 ​

칸설명
데이터베이스 · 대상 제품 · 대상 버전DDL을 만들 DB와 버전. 고르면 미리보기가 바로 바뀝니다. 대상 버전은 .erm이 아니라 이 PC에 파일마다 기억됩니다.
환경테이블스페이스 환경(모델 › 옵션…의 테이블스페이스 환경). 테이블스페이스 속성을 이 환경 값으로 씁니다.
카테고리전체 또는 카테고리 하나로 범위를 좁힙니다.
출력 파일저장할 경로. **찾아보기…**로 고릅니다. 이미 있는 파일이면 덮어쓸지 묻습니다.
인코딩 · 줄바꿈파일의 문자 인코딩과 줄 끝.
저장한 뒤 파일 열기저장한 뒤 그 파일을 엽니다.

버전만 바꿔 미리 보는 중이면 "저장하면 이 문서의 대상 버전이 바뀝니다"가 보입니다. 미리보기만 보고 닫으면 대상 버전은 그대로입니다.

생성 대상 ​

만들 문장을 하나씩 켜고 끕니다. 모두 켜기로 전부 켜고, 삭제 절 끄기로 삭제 문장만 끕니다.

묶음항목
삭제인덱스 삭제 · 뷰 삭제 · 트리거 삭제 · 테이블 삭제 · 시퀀스 삭제 · 테이블스페이스 삭제
생성테이블스페이스 생성 · 시퀀스 생성 · 테이블 생성 · 외래 키 생성 · 트리거 생성 · 뷰 생성 · 인덱스 생성

처음 실행하는 DB에서는 삭제 문장이 "없음" 오류를 낼 수 있습니다. 존재 검사 문법이 있는 DB는 그것을 쓰고, 없는 DB는 스크립트 맨 위에 안내 주석을 넣습니다.

주석 ​

항목설명
DB 주석 생성 (COMMENT 등)테이블·컬럼 주석을 DB 주석 문장으로 만듭니다.
객체 앞 SQL 주석 줄 (-- 주석)테이블 등 객체 앞에 -- 주석 줄을 넣습니다.
컬럼 앞 SQL 주석 줄컬럼 앞에도 주석 줄을 넣습니다.
주석값주석에 쓸 내용 — 설명 · 논리명 · 논리명 : 설명
주석값 안의 줄바꿈을 바꾸기켜면 주석 안의 줄바꿈을 바꿀 문자열로 바꿉니다. 비우면 줄바꿈을 지웁니다.

옵션 ​

항목설명
IF NOT EXISTS로 만들기테이블·인덱스·시퀀스만 대상입니다. 이 문법이 없는 DB는 존재 검사로 감싸거나 경고로 알립니다. 완전히 다시 실행할 수 있게 하려면 삭제 절과 함께 쓰세요.
스키마 접두어 빼기접속한 사용자의 기본 스키마에 만듭니다. 다른 스키마에 같은 이름이 있으면 그 이름만 접두어를 남깁니다.
Oracle 기본 형식 사용 (boolean)Oracle 23 이상에서 참/거짓 컬럼을 number(1,0) 대신 boolean으로 만듭니다.
빈 줄이 있으면 SET SQLBLANKLINES ON 넣기주석에 빈 줄이 있을 때만 스크립트 맨 앞에 넣어, SQL*Plus가 빈 줄에서 문장을 끊지 않게 합니다. 끄면 넣지 않고 경고합니다.
테이블스페이스도 지우기삭제 절에 DROP TABLESPACE를 넣습니다. 그 테이블스페이스의 다른 스키마 데이터까지 지워질 수 있습니다. 생성 대상의 테이블스페이스 삭제도 켜져 있어야 합니다.

저장을 누르면 환경 · 카테고리 · 출력 파일 · 인코딩 · 줄바꿈 · 저장한 뒤 파일 열기와 생성 대상 · 주석 탭의 설정이 문서(.erm)에 저장되어 다음에도 쓰입니다. 반면 대상 제품(MySQL·MariaDB 선택) · 대상 버전과 "옵션" 탭의 항목은 .erm이 아니라 이 PC의 파일별 기록에 기억됩니다. 창을 열어 설정만 바꿔 보고 저장 없이 닫으면 어느 쪽도 바뀌지 않습니다.

미리보기와 저장 ​

  • 창의 미리보기에 만들어질 SQL이 보입니다. 큰 글이면 줄 번호·색 표시를 끄고 보여 줍니다.
  • 저장을 누르면 파일로 씁니다. 앱 창 오른쪽 아래 알림의 폴더 열기로 탐색기에서 그 파일을 고른 채 폴더를 엽니다.
  • 저장 결과는 "DDL을 저장했습니다 (경고 n개 — 문제 목록)"처럼 알려 줍니다.

버전별 문법과 경고 ​

  • 고른 DB 버전에서 쓸 수 없는 문법은 빼거나 바꾸고 경고로 알립니다. 경고는 창에 개수로 보이고 문제 목록에도 남습니다.
  • 관계의 ON UPDATE·ON DELETE처럼 그 DB가 지원하지 않는 동작은 지원하는 동작으로 바꾸거나 생략합니다. 관계 정보 창에서 미리 알려 줍니다.
  • 물리명·형식이 없는 컬럼이 있는 테이블은 만들지 않고 "테이블 n개를 만들지 않음 — 물리명·형식 없는 컬럼"으로 알립니다. 목록을 더블클릭하면 캔버스에서 그 테이블을 보여 줍니다.
  • 설계 검사의 오류(DDL을 실행하면 실패할 문제)가 있으면 창에 "이 문서에 DDL 실행을 실패하게 하는 오류가 n개 있습니다"가 보이고 문제 목록 보기로 바로 갑니다. 예외로 숨긴 오류는 이 수에 넣지 않습니다. 저장은 막지 않습니다.

팁

버전을 모르면 "버전 미지정"으로 두어도 됩니다. 그 DB의 가장 낮은 지원 버전부터 되는 문법으로 만들므로 대부분의 버전에서 실행됩니다.
