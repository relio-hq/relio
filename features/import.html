가져오기와 다른 형식 ​

SQL(CREATE TABLE)·DBML·Mermaid·Markdown에서 모델을 가져오는 방법과, 다른 .erm 파일에서 객체를 가져오는 방법을 설명합니다. DB에 접속해 가져오기는 DB 연동에 있습니다.

가져오기 메뉴 ​

메뉴 › 항목하는 일
파일 › 가져오기 ▸ › DB에서…DB에 접속해 구조를 가져옵니다. DB 연동
파일 › 가져오기 ▸ › 파일에서…다른 .erm 파일의 객체를 골라 넣습니다.
파일 › 가져오기 ▸ › SQL·DBML·Mermaid·Markdown에서…글 형식 파일이나 붙여 넣은 글에서 모델을 만듭니다. 문서가 없어도 쓸 수 있습니다.

.sql · .ddl · .dbml · .mmd · .mermaid · .md 파일을 창에 끌어다 놓거나 파일 › 열기…로 열어도 이 가져오기 창이 열립니다(바로 넣지 않음).

SQL·DBML·Mermaid·Markdown에서 가져오기 ​

입력 ​

칸설명
입력파일 또는 붙여넣기. 파일은 32MB, 붙여넣기는 8MB까지입니다.
파일 경로.sql · .ddl · .dbml · .mmd · .mermaid · .md. **찾아보기…**로 고릅니다.
인코딩**자동 (BOM·UTF-8)**이 기본입니다. BOM이 없고 UTF-8이 아닌 파일은 인코딩을 고르라고 묻습니다(추측하지 않음).
입력 형식자동 판별 · SQL · DBML · Mermaid · Markdown
방언SQL일 때 — 자동 판별 · PostgreSQL · MySQL/MariaDB · Oracle · SQL Server · 표준 SQL

pg_dump·mysqldump·SSMS 스크립트·Oracle DDL처럼 CREATE TABLE이 든 파일을 그대로 읽습니다. 읽을 수 없는 문장은 건너뛰고 경고로 알립니다.

가져올 곳과 옵션 ​

  • 가져올 곳 — 새 문서(이름 없는 새 탭) 또는 현재 문서에 합치기. 열린 문서가 없거나 읽기 전용이면 새 문서만 됩니다.
  • 새 문서의 DB는 형식이 알려 주는 DB를 씁니다. 형식이 DB를 알려 주지 않으면 고른 DB를 씁니다(SQL 방언을 알면 그 DB).
  • 주석 해석 — 주석을 어디에 넣을지: 자동 (논리명 : 설명) · 설명으로만 · 논리명으로만.
  • 따옴표 없는 이름을 DB 규칙대로 (대문자·소문자) — 켜면 따옴표 없는 이름을 그 DB 규칙대로 대문자나 소문자로 바꿉니다.

미리 보기 ​

미리 보기를 누르면 문서에 넣기 전에 찾은 테이블 · 컬럼 · 관계 · 인덱스 수와 경고·참고를 봅니다. 큰 파일은 "읽는 중… n초"가 보이고, 취소를 누르면 멈추고 아무것도 바꾸지 않습니다. 뒤로로 입력을 고칩니다.

이름이 겹칠 때 ​

현재 문서에 합칠 때 이름이 같은 객체가 있으면 가져오기를 누른 뒤 처리 방법을 고릅니다.

처리하는 일
덮어쓰기내용만 바꾸고 위치·색·카테고리는 그대로 둡니다.
건너뛰기그 객체는 가져오지 않습니다.
이름 바꿔 추가다른 이름으로 더합니다.

남은 것 모두에 적용으로 한 번에 정하거나 "(하나씩 고르기)"로 객체마다 정합니다. 합친 결과는 되돌리기 한 번(Ctrl+Z)으로 모두 취소됩니다.

결과 ​

가져온 뒤 가져오기 결과(또는 합치기 결과) 창에 만든(합친) 객체 수와 경고가 줄:열 · 종류 · 내용 · 건너뛴 글로 나옵니다. 목록 복사로 복사할 수 있고, 같은 경고가 문제 목록에도 남습니다.

팁

다른 도구에서 만든 SQL을 가져와 Relio에서 다듬은 뒤, 다시 DBML·Mermaid로 내보내기할 수 있습니다. 명령줄 relio import로 화면 없이 .erm을 만들 수도 있습니다. 명령줄

다른 .erm 파일에서 가져오기 ​

파일 › 가져오기 ▸ › 파일에서…를 누르고 .erm 파일을 고르면 가져올 객체 (이 파일의 DB: …) 목록이 나옵니다. 테이블·뷰·노트·컬럼 그룹·시퀀스·트리거·테이블스페이스를 종류별로 묶어 보여 주며, 체크한 것을 지금 문서에 넣습니다(파일에 없는 종류는 나오지 않고, 이미지는 고를 수 없습니다). 처음에는 모두 체크되어 있고, 아래 단어를 병합을 켜 두면 내용이 같은 단어를 하나로 합칩니다.

  • 이름이 같은 객체는 위와 같이 덮어쓰기 · 건너뛰기 · 이름 바꿔 추가를 고릅니다.
  • 카테고리는 이름(앞뒤 공백·대소문자 무시)이 같으면 새로 만들지 않고 그 카테고리에 소속만 더합니다.
  • 가져오기 전체가 되돌리기 한 번입니다.
