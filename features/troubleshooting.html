도움말과 문제 해결 ​

도움말 메뉴(사용 설명서·새 소식·Relio 정보 등)와, 파일이 열리지 않을 때·갑자기 꺼졌을 때·DB에 접속되지 않을 때 할 일, 진단 기록, 문제 알리기, 내 정보가 저장되는 곳, 설치·지우기를 설명합니다.

사용 설명서 ​

도움말 › 사용 설명서…(F1)는 앱에 들어 있는 짧은 설명서를 창으로 엽니다. 인터넷 없이 볼 수 있고, 앱의 표시 언어를 따릅니다(그 언어 설명서가 없으면 영어). 더 자세한 설명은 이 가이드에 있습니다.

  • 절마다 한 쪽 — 설명서는 절(시작하기 · 단축키 · … · AI 도구 연결 · 문제 해결 등) 하나를 한 쪽으로 보여 줍니다. 목차에서 절을 누르거나, 위의 이전 · 다음(Alt+← · Alt+→)으로 앞뒤 절로 넘깁니다.
  • 설명서에서 찾기 — 찾는 글이 있는 절마다 목차 옆에 일치 수가 보이고, 이전 · 다음 일치로 옮겨 다닙니다.
  • 복사 — 코드 상자와 긴 명령에는 복사 단추가 있어 명령줄이나 AI 도구 등록 줄을 그대로 복사할 수 있습니다.
  • 다른 창의 설명서 보기(예: AI 도구 연결 알림)는 그 내용의 절을 바로 엽니다.

새 소식 ​

  • 새 버전을 설치한 뒤 처음 실행하면 "새 소식 — Relio …" 창이 한 번 열립니다. 이때만 보이는 다시 보지 않기를 켜고 닫으면 다음 버전부터는 저절로 열리지 않습니다.
  • 도움말 › 새 소식…으로 언제든 다시 엽니다.
  • 이번 버전의 변경은 펼쳐 보이고, 이전 버전은 최근 다섯 개가 "버전 · 한 줄 요약" 줄로 접혀 있어 누르면 펼쳐집니다. 전체 변경 기록 보기를 누르면 나머지 버전도 앱 안에서 펼칩니다(인터넷을 열지 않음).
  • 창 아래에 지금 버전과 Releases 페이지 열기 링크, 업데이트 확인 단추가 있습니다.

Relio 정보 ​

도움말 › Relio 정보는 버전, Releases 페이지 열기 링크, 업데이트 확인 단추와 "자동 업데이트 확인: 켜짐 / 꺼짐 / 정하지 않음(꺼진 채)" 상태 한 줄을 보여 줍니다. 오픈소스 라이선스를 누르면 Relio가 쓰는 오픈소스 구성 요소의 라이선스 전문을 읽기 전용 창으로 봅니다. 명령줄 경로 복사는 지금 쓰는 실행 파일의 전체 경로를 따옴표째 복사합니다(도구 › 명령줄·AI 연결… 창에도 같은 단추가 있습니다) — relio가 PATH에 없을 때 명령줄이나 AI 도구 등록에 붙여 씁니다.

자주 만나는 문제 ​

증상할 일
파일이 열리지 않습니다오류 창에 줄·칸 위치가 나옵니다. 너무 깊게 중첩된 파일 같은 비정상 구조는 안전을 위해 열지 않습니다. 고쳐서 열린 경우에는 고친 내역을 확인하세요. 파일 › 고쳐서 열기
다른 프로그램이 파일을 바꿨다고 나옵니다창으로 돌아오면 다시 읽을지 묻습니다. 저장하지 않은 변경이 있으면 합치기…(내 변경과 바깥 변경을 모델 단위로 합침) · 다시 읽기 (내 변경 버림) · 내 변경 유지 중에서 고릅니다.
Git 병합 뒤 파일이 열리지 않습니다충돌 표시(<<<<<<<)가 남은 파일이면 안내 창에서 **Git 병합 충돌 풀기…**로 바로 갑니다. 줄 단위 "양쪽 받기"로 망가진 파일은 어느 테이블·컬럼인지 고친 내역에 나오고, 병합을 모델 단위로 다시 하기로 다시 합칠 수 있습니다. Git과 합치기
갑자기 꺼졌습니다다시 시작하면 자동 백업에서 복구할지 묻습니다. 백업은 설정 폴더의 backup 폴더에도 있습니다. 파일 › 자동 백업과 복구
DB에 접속되지 않습니다서버·포트·DB 이름·방화벽을 확인하세요. 자체 서명 인증서를 쓰는 서버는 접속 창 고급 ▾의 **서버 인증서 신뢰 (자체 서명 인증서)**를 켭니다. Oracle은 Instant Client 폴더 등록, DB2·Informix·MS Access는 ODBC 드라이버 설치를 확인하세요. DB 연동
"보안상 쓰지 않습니다" 안내문서에 적힌 드라이버 파일·네트워크 경로·DSN 파일을 막은 것입니다. 믿을 수 있는 값이면 환경 설정에 등록하거나 접속 창에 직접 입력하세요.
설치 파일 실행 때 Windows 경고설치 파일은 아직 코드 서명을 하지 않아 "Windows의 PC 보호" 창이 뜰 수 있습니다. 받은 곳이 맞는지 확인한 뒤 추가 정보 → 실행을 누르세요. 회사 PC에서 서명 없는 프로그램 실행이 막혀 있으면 사내 관리자에게 문의하세요.
화면 글자가 이상합니다도구 › 환경 설정 › 일반에서 표시 언어를 고르세요.
새 버전 확인이 안 됩니다업데이트 › 확인이 안 될 때
ERMaster에서 열면 형식이 비어 보입니다아래 ERMaster에서 형식이 비어 보일 때
저장할 때마다 파일 전체가 바뀐 것으로 Git에 잡힙니다줄 끝이 달라서입니다. .gitattributes에 *.erm text eol=lf를 넣으세요. Git으로 함께 쓰기

ERMaster에서 형식이 비어 보일 때 ​

Relio에만 있는 형식(예: json·jsonb·vector)을 쓴 컬럼은 ERMaster에서 열면 형식 칸이 비어 보입니다. 컬럼 정보 창의 형식 목록에는 이런 형식 옆에 "ERMaster에서는 형식이 비어 보여요"가 붙어 미리 알 수 있습니다. Relio에서는 그대로 쓸 수 있으므로, ERMaster와 섞어 쓰는 팀이라면 두 도구에 모두 있는 형식을 고르세요.

진단 기록 ​

  • Relio는 오류·시작 시간 같은 진단 정보를 이 PC의 설정 폴더 logs에만 남깁니다(최근 7일, 모두 합쳐 5MB까지).
  • 인터넷으로 보내지 않고, 파일 내용·테이블 이름·경로·사용자 이름은 들어가지 않습니다.
  • Relio가 예기치 않게 닫혔다면 다음 실행 때 창 아래 띠로 한 번 알려 주고 **문제 보고…**로 바로 갈 수 있습니다.
  • 남기고 싶지 않으면 도구 › 환경 설정 › 일반 › 진단에서 진단 기록 남기기를 끄고, 진단 기록 지우기로 지웁니다.

문제 알리기 ​

도움말 › 문제 보고…를 엽니다. 창에 Relio 버전·Windows 버전과 적을 칸(재현 순서 · 기대한 것 · 실제로 일어난 것)이 보입니다.

단추하는 일
GitHub에서 보고기본 브라우저로 GitHub 이슈 작성 화면을 엽니다. 버전 정보가 양식에 자동으로 들어갑니다(GitHub 계정 필요).
보고 내용 복사GitHub를 쓸 수 없을 때, 같은 버전 정보와 적을 칸을 복사해 메일·메신저에 붙여 넣습니다.
익명화 사본 저장…열린 문서에서 이름·설명·노트·기본값 등을 지운 사본(구조만 남음)을 저장합니다. 지금 문서는 그대로입니다.
진단 기록 폴더 열기 · 최근 기록 복사진단 기록 파일을 보거나 마지막 200줄을 복사해 보고에 붙입니다.
  • 어느 쪽이든 파일 내용·경로·사용자 이름은 넣지 않습니다.
  • 먼저 샘플(도움말 › 샘플 열기 ▸)로도 같은 문제가 생기는지 확인해 주세요. 샘플로 재현되면 확인이 빠릅니다.

주의

회사 .erm 파일이나 화면 캡처는 올리지 마세요. 테이블 구조 자체가 회사 정보입니다. 파일 때문에 생긴 문제라면 **익명화 사본 저장…**으로 만든 사본을 붙이세요.

설치·지우기 ​

  • 설치 — 설치 파일(Relio_<버전>_x64-setup.exe)을 실행합니다. 관리자 권한 없이 지금 사용자 계정에만 설치됩니다. 바탕화면 바로가기와 "명령줄에서 relio 쓰기"(사용자 PATH에 설치 폴더 추가, 기본 꺼짐)는 설치 마지막 화면에서 고르고, 다시 설치하거나 업데이트할 때 그 선택을 따릅니다. 명령줄
  • 실행판 — Relio_<버전>_x64_portable.zip을 풀고 relio.exe를 실행합니다. 설치판과 같은 설정 폴더를 씁니다.
  • 지원 — Windows 10 · 11(64비트). 화면에 쓰는 Microsoft Edge WebView2는 Windows 10 · 11에 기본으로 들어 있습니다.
  • 업데이트 — Relio 안에서 받거나, 새 설치 파일을 그대로 실행하면 덮어 설치되고 설정은 남습니다. 업데이트
  • 지우기 — Windows 설정 › 앱에서 Relio를 제거합니다. 설정·연결 목록·백업(%APPDATA%\Relio)은 남아서 다시 설치하면 그대로 씁니다.
  • 흔적까지 지우기 — 제거한 뒤 %APPDATA%\Relio 폴더를 지우고, Windows 자격 증명 관리자에서 relio:로 시작하는 항목을 지웁니다(먼저 도구 › 환경 설정 › 암호에서 지워도 됩니다).
