환경 설정 ​

도구 › 환경 설정…의 쪽별 항목을 설명합니다. 바꾸는 즉시 저장되고, 모든 문서에 함께 쓰입니다.

환경 설정 창 왼쪽에서 쪽을 고릅니다: 일반 · 글로벌 그룹 · 번역 사전 · Excel 템플릿 · DB 연결 · 단축키 · 암호 · 설계 검사. 설정은 이 PC의 %APPDATA%\Relio에 있고, 앱을 지웠다 다시 설치해도 남습니다.

이 PC에 파일마다 기억한 것 ​

파일마다 대상 DB 버전 · DB 연결 · 암호 저장 방식(그리고 설계 검사 예외, 글 형식 내보내기 설정 등)을 이 PC에 기억합니다. 표에 파일·대상·연결이 보이고, 줄마다 지우기, 없어진 파일의 기록은 없는 파일 기록 지우기로 한꺼번에 정리합니다. 파일을 다른 곳으로 옮기면 기록은 새로 시작합니다.

강조 ​

마우스 올림·선택 연결 강조, 나머지 흐리게, 흐림 정도, 강조 효과, 움직임 줄이기. 찾기와 강조 › 강조 설정

진단 ​

진단 기록 남기기 — 오류·시작 시간 같은 진단 정보를 이 PC의 설정 폴더에만 남깁니다(최근 7일). 인터넷으로 보내지 않고, 파일 내용·이름·경로는 들어가지 않습니다. 끄면 새 기록을 쓰지 않습니다. 진단 기록 지우기로 지금까지의 기록을 지웁니다. 도움말과 문제 해결 › 진단 기록

글로벌 그룹 ​

글로벌 그룹은 여러 파일이 함께 쓰는 컬럼 묶음입니다. 이 PC의 앱 설정에 저장되고, 문서에는 문서에 넣기로 복사합니다. 이 쪽에서는 목록(그룹 이름·컬럼 수)을 보고 **글로벌 그룹 관리…**로 고칩니다. 모델 메뉴 › 그룹 관리

번역 사전 ​

DB에서 가져올 때 물리명으로 논리명을 채우는 사전 목록입니다.

  • 번역 사전 파일은 UTF-8 글 파일로, 한 줄에 원어와 번역어를 쉼표로 나눠 적습니다(예: customer,고객). 쉼표가 없는 줄은 건너뜁니다.
  • 표에 이름 · 항목 수 · 파일 위치가 보입니다. 앱에 포함된 내장 사전은 늘 맨 위입니다.
  • 새로 만들기… · 추가(파일)… · 제거(목록에서만 빼고 파일은 지우지 않음) · 위로 · 아래로 · 파일 열기.
  • 위에 있는 사전이 먼저 쓰입니다. 문서마다 쓸 사전은 모델 › 번역 관리…에서 고릅니다.

Excel 템플릿 ​

  • 내장 템플릿 — 앱에 들어 있는 템플릿입니다(한국어 — 테이블 정의서 등). **파일로 저장…**해 고쳐 쓴 뒤 사용자 템플릿으로 추가할 수 있습니다.
  • 사용자 템플릿 — Excel 내보내기의 템플릿 목록에 함께 나옵니다. words·loops 시트와 템플릿 시트가 있는 .xlsx 또는 .xls 파일입니다. 추가… · 제거.

내보내기 › Excel

DB 연결 ​

  • 저장한 연결 — DB 접속 창에서 저장한 연결의 이름 · 위치 · 사용자. 이름 바꾸기 · 지우기. 암호는 여기 저장하지 않습니다.
  • DB 클라이언트 — Oracle Instant Client 폴더(oci.dll이 있는 폴더의 전체 경로, 네트워크 경로 불가, 비우면 PATH에서 찾음, 바꾸면 다시 시작해야 적용), DB2·Informix·MS Access마다 ODBC 드라이버(드라이버 이름 또는 .dll 전체 경로, 비우면 기본 이름). 보안상 드라이버 파일과 Oracle 폴더는 여기 등록한 것만 씁니다.
  • 클라이언트 설정 저장으로 저장합니다.

DB 연동

단축키 ​

모든 단축키를 표(분류 · 동작 · 키)로 보고 바꿉니다. 도움말 › 단축키 목록…으로도 이 쪽이 열립니다.

  • 바꾸기를 누른 뒤 새 키를 누릅니다(Esc = 취소). 바꾼 단축키는 메뉴에도 바로 보입니다.
  • 기본값으로 그 줄을 되돌리고, 없애기로 키를 뺍니다. 모두 기본값으로로 전부 되돌립니다.
  • 다른 동작과 겹치는 키는 "겹침: …"으로 알립니다.
  • 방향키(1칸 이동) · Shift+방향키(10칸) · Tab(다음 노드) · Space(누르고 끌어 화면 이동) · Ctrl+마우스 휠(확대·축소)은 바꿀 수 없는 고정 키입니다.
