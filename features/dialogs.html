정보 창 ​

캔버스의 대상을 고치는 창 — 테이블·컬럼·간편 등록·인덱스·뷰·관계·노트 연결·이미지 정보 창 — 의 항목을 설명합니다. 단어 사전·그룹·시퀀스·옵션처럼 모델 메뉴에서 여는 창은 모델 메뉴에 있습니다.

정보 창은 캔버스에서 노드를 더블클릭하거나 선택한 뒤 Enter를 누르면 열립니다. 아웃라인에서 테이블·뷰를 더블클릭해도 열리고, 테이블 아래 컬럼 줄을 더블클릭하면 그 컬럼을 선택한 채 테이블 정보 창이 열립니다. 컬럼을 넣는 순서는 빠른 시작의 테이블·컬럼·관계 그리기를 보세요.

테이블 정보 ​

위에 논리명과 물리명이 있고, 아래는 탭 여섯 개입니다.

탭내용
속성컬럼 표(기본 키(PK) · 외래 키(FK) · 물리명 · 논리명 · 형식 · NOT NULL · UNIQUE)와 추가 · 편집 · 삭제 · 위·아래 · 간편 등록. 아래에 그룹을 고르는 칸, 그룹 항목을 테이블에 추가, 그룹 컬럼 표, 그룹 관리…
설명문서·주석에 나오는 여러 줄 설명
복합 고유 키키 목록, UNIQUE KEY 제약 조건명, 컬럼 체크 목록, 추가 · 업데이트 · 삭제
제약/옵션테이블 제약 조건, 기본 키 제약 조건명, 옵션(DDL 테이블 끝에 붙습니다)
인덱스인덱스 목록과 추가 · 편집 · 삭제 — 아래 "인덱스 정보"
고급 설정DB별 테이블 옵션(스키마·테이블스페이스, MySQL이면 스토리지 엔진·문자 집합·데이터 정렬·TEXT 형식을 기본 키로 할 때 길이 등)
  • 컬럼 표의 칸(물리명·논리명·형식·NOT NULL·UNIQUE)은 표에서 바로 고칠 수 있습니다. 행을 더블클릭하거나 고르고 Space를 누르면 컬럼 정보 창이 열립니다.
  • 캔버스에서 컬럼을 고른 채 열면 그 행이 골라진 채로 열립니다.
  • 입력하는 동안 칸 아래 한 줄로 문제를 알려 줍니다(막지는 않음). 설계 검사와 추천 › 입력하는 자리에서 알림
  • 지울 수 없는 컬럼 — FK 컬럼(관계를 지워야 함)과 다른 테이블이 참조하는 컬럼은 지울 수 없습니다. 그때 관계까지 삭제 단추로 관계와 함께 지울 수 있고, 확인을 누르면 한 번에 적용되며 되돌릴 수 있습니다.
  • 복합 고유 키는 컬럼을 하나 이상 골라야 하고, 같은 컬럼 조합의 키를 두 번 만들 수 없습니다. 제약 조건명은 영문자·숫자·_만 쓸 수 있고, 비우면 이름 없이(DB가 정함) 만듭니다.

컬럼 정보 ​

기본 탭 ​

칸설명
기본 키 · NOT NULL · UNIQUE · AUTO_INCREMENT기본 키를 켜면 NOT NULL도 켜지고 잠깁니다. AUTO_INCREMENT는 기본 키이고 정수 형식일 때만, 테이블에 다른 자동 증가 컬럼이 없을 때만 켤 수 있습니다.
단어단어 사전의 단어를 고르면 이름·형식·길이·설명이 그 단어 값으로 채워집니다. 필터 칸으로 목록을 거릅니다. 비워 두면 입력한 값으로 새 단어를 만듭니다.
논리명 · 물리명물리명만 치면 논리명이 따라 채워집니다. 논리명을 직접 고치면 그때부터 따로 갑니다. 물리명 제안은 번역 사전으로 논리명에서 물리명 후보를 보여 주고 적용으로 넣습니다.
형식 · 길이 · 소수형식 목록은 ERMaster와 같은 공통 형식 이름입니다. 지금 DB에서 다른 이름으로 만들어지는 형식이면 칸 아래에 "이 DB(…)에서는 … 형식으로 만들어져요"가 나옵니다. 길이·소수를 받지 않는 형식이면 그 칸이 흐려집니다. FK 컬럼은 부모 컬럼의 형식을 따릅니다.
UNSIGNED · ZEROFILL · BINARYMySQL·MariaDB일 때만 보입니다.
enum/set 인수형식이 enum·set일 때 값 목록.
기본값값을 치거나 현재 일시 · 빈 문자열을 고릅니다.
설명문서·주석에 나오는 설명.

단어를 쓰는 컬럼 — 단어를 쓰는 컬럼에서 이름·형식을 고치면 그 단어 자체가 바뀌어 같은 단어를 쓰는 모든 컬럼에 반영됩니다. 칸 옆에 "이 단어를 쓰는 컬럼 n개에 반영"이 보이고, 이 컬럼만 바꾸려면 이 컬럼만 새 단어로 분리를 누릅니다.

입력 중 추천 — 물리명·논리명을 치면 칸 위에 후보가 나옵니다. ↓로 고르고 Enter로 받습니다. 잘못 받았으면 채우기 취소. 자세한 것은 설계 검사와 추천에 있습니다.

정보 탭 ​

UNIQUE KEY 제약 조건명 · 컬럼 제약 조건 · 문자 집합 · 데이터 정렬, 그리고 AUTO_INCREMENT를 켰을 때 쓰는 AUTO_INCREMENT 설정… 단추가 있습니다. AUTO_INCREMENT 설정 창은 그 DB가 쓰는 값만 보입니다(MySQL·MariaDB·SQL Server·MS Access는 시작·증가, Informix는 시작, 그 밖은 시작·증가·최솟값·최댓값·캐시·순환(CYCLE)). SQLite에는 이 단추가 없습니다.

간편 등록 ​

여러 컬럼을 표 하나로 한 번에 넣습니다. 열은 논리명 · 물리명 · 형식 · 길이 · 소수이고, Excel에서 복사한 표를 첫 칸에 붙여 넣을 수 있습니다. 행 추가로 줄을 늘립니다. 테이블 정보·뷰 정보·그룹 관리 창에 있습니다.

인덱스 정보 ​

  • UNIQUE · FULL TEXT(MySQL·MariaDB만) 체크, 테이블명(읽기 전용), 인덱스명, 인덱스 유형(그 DB가 쓰는 방식만), 설명.
  • 왼쪽 모든 컬럼에서 고르고 추가 ▶ / ◀ 빼기로 오른쪽 **인덱스 컬럼 (컬럼명 · 내림차순)**에 넣고, 위로 · 아래로로 순서를 정합니다. 내림차순은 지원하는 모든 DB에서 쓸 수 있습니다.
  • 인덱스명을 비워 두고 컬럼을 고르면 이름을 지어 줍니다.

뷰 정보 ​

탭은 속성(테이블 정보와 같은 컬럼 표) · SQL · 설명 · 고급 설정입니다. SQL 칸은 줄 번호와 색 표시가 있고, SQL이 비어 있으면 확인을 누를 수 없습니다. SQL에서 컬럼 가져오기는 SELECT 목록을 읽어 컬럼 표를 채웁니다.

관계 정보 ​

관계선을 더블클릭하면 열립니다.

  • 제약 조건명 — 비우면 이름 없이(DB가 정함) 만듭니다.
  • ON UPDATE · ON DELETE — RESTRICT · CASCADE · NO ACTION · SET NULL · SET DEFAULT. 지금 DB가 지원하지 않는 동작을 고르면 칸 옆에 "이 DB에서는 NO ACTION으로 출력됨"이나 "이 DB에서는 생략됨(출력 안 함)"이 나옵니다.
  • 부모 — 참조 테이블(읽기 전용), 참조 대상(기본 키 또는 복합 고유 키), 다중성(1 · 0..1).
  • 자식 — 다중성(1..n · 0..n · 1 · 0..1), FK 컬럼 목록.

참조 대상을 바꾸면 자식의 FK 컬럼을 새 대상에 맞게 다시 만듭니다(되돌리기 한 번). 관계를 지울 때는 FK 컬럼을 함께 지울지 묻습니다.

기존 컬럼을 사용한 관계 ​

팔레트의 기존 컬럼을 사용한 1:N 관계로 부모 → 자식을 누르면 열립니다. **참조 대상(부모 기본 키)**을 고르고, 표에서 대상 컬럼마다 자식의 FK 컬럼을 고릅니다. 이름이 맞는 컬럼은 미리 골라 두고 "이름으로 골랐습니다"를 표시합니다. 형식이 다른 컬럼을 고르면 경고합니다.

노트 연결선·이미지 ​

  • 연결 정보 — 노트 연결선을 더블클릭하면 열립니다. 선 색을 고르거나 기본 색으로 되돌립니다.
  • 이미지 정보 — 이미지를 더블클릭하면 열립니다. 색상(°) · 채도(%) · 밝기(%) · 투명도(0–255) 와 가로세로 비율 유지. 미리보기에 바로 반영됩니다.
