업데이트 ​

새 버전 자동 확인, 업데이트 확인, Relio 안에서 새 버전을 받아 설치하기, 설치 없이 쓰는 실행판의 업데이트를 설명합니다. 1.0.0부터 쓸 수 있습니다.

처음 실행할 때 알림을 켜는 방법은 빠른 시작의 처음 시작하기에 있습니다.

자동 확인 켜기·끄기 ​

  • 처음 실행하면 창 아래에 "새 버전이 나오면 알려 드릴까요? Relio는 하루 한 번 공개 Releases에서 버전 정보만 받습니다." 띠가 뜹니다. 알려 주세요는 켜고, 괜찮아요는 끕니다. 답하지 않고 닫으면 정하지 않은 채(꺼진 것과 같게) 둡니다.
  • 나중에 바꾸려면 도구 › 환경 설정 › 일반의 **새 버전 자동 확인 (하루 한 번)**을 켜거나 끕니다. 켜면 그 자리에서 한 번 확인합니다.
  • 켜 두면 앱을 시작하고 조금 뒤 배경에서, 마지막 확인에서 하루가 지났을 때만 확인합니다. 실패해도 다시 시도하지 않고 다음 날 확인합니다.
  • 설정 아래에 마지막 확인 결과("마지막 확인: … — 최신 버전입니다" / "… — 새 버전 …" / "… — 확인하지 못했습니다")가 보입니다.

무엇을 주고받나 ​

확인은 공개 Releases의 정해진 주소에서 버전 정보 파일을 받기만 합니다. Relio 버전·PC 정보 같은 것을 보내지 않습니다. 다만 GitHub는 접속한 IP 주소를 볼 수 있습니다. 확인 결과는 이 PC의 앱 설정에만 남습니다.

직접 확인하기 ​

도움말 › **업데이트 확인…**을 누르면 자동 확인 설정과 관계없이 바로 확인합니다. Relio 정보 창과 새 소식 창의 업데이트 확인 단추도 같습니다. 결과는 작은 창에 나옵니다.

  • 최신이면 "지금 쓰는 버전이 최신입니다 (…)".
  • 새 버전이 있으면 아래 안내 창.
  • 실패하면 이유와 Releases 페이지 열기 링크(아래 "확인이 안 될 때").

새 버전 안내 ​

자동 확인에서 새 버전을 찾으면 창 오른쪽 아래에 "Relio … 버전을 설치할 수 있습니다" 알림이 뜹니다. 자세히를 누르면 안내 창이 열립니다.

  • 제목 "새 버전이 있습니다", 지금 … → 새 …, 배포 날짜, 변경 요약, 전체 변경 기록 보기 링크.
  • 지금 설치 — 받아서 설치합니다(아래).
  • 나중에 — 닫습니다. 다음 자동 확인 때 다시 알립니다.
  • 이 버전 건너뛰기 — 이 버전은 다시 알리지 않습니다. 더 새 버전이 나오면 다시 알립니다. 직접 확인할 때는 건너뛴 버전이어도 "건너뛰기로 한 버전입니다"와 함께 보여 줍니다.

설치 흐름 ​

  1. 지금 설치를 누르면 같은 창에 진행 막대("내려받는 중… 받은 크기 / 전체")가 보입니다. 취소할 수 있고, 그동안 다른 화면을 써도 됩니다.
  2. 받은 파일의 서명을 확인합니다. 맞지 않으면 설치하지 않습니다.
  3. 저장하지 않은 문서가 있으면 "저장하지 않은 문서 n개가 있습니다. 설치하려면 Relio를 닫아야 합니다."와 함께 모두 저장하고 설치 · 저장하지 않고 설치 · 취소를 묻습니다.
  4. "설치를 시작합니다. 설치가 끝나면 Relio가 다시 열립니다." 뒤 Relio가 닫히고 설치가 진행된 다음 다시 열립니다.

진행 중인 작업(내보내기 등)이 있으면 끝난 뒤 설치할 수 있습니다. 설정·연결 목록·백업은 그대로 남습니다.

설치 없이 쓰는 실행판 ​

Relio_<버전>_x64_portable.zip을 풀어 쓰는 실행판도 확인과 안내는 같습니다. 다만 자동으로 설치하지 않고, 안내 창에 "실행판은 자동으로 설치하지 않습니다. 새 zip을 받아 바꿔 쓰세요."와 내려받기 페이지 열기가 나옵니다. 새 zip을 받아 풀고 그 relio.exe를 씁니다. 설정 폴더는 설치판과 같아서 설정이 그대로 이어집니다.

확인이 안 될 때 ​

업데이트 서버에 연결하지 못했습니다. 인터넷 연결이나 회사 네트워크 설정을 확인하세요.인터넷·프록시를 확인하거나 Releases 페이지에서 직접 받습니다.
업데이트 정보를 읽지 못했습니다. 잠시 뒤 다시 확인하거나 Releases 페이지에서 직접 받으세요.잠시 뒤 다시 확인합니다.
받은 파일의 서명이 맞지 않아 설치하지 않았습니다. …파일이 손상됐거나 바뀌었을 수 있습니다. Releases 페이지에서 직접 받습니다.
새 버전을 받지 못했습니다(…).다시 시도하거나 디스크 공간을 확인합니다.
설치하지 못했습니다. Relio는 지금 버전 그대로입니다. …Releases 페이지에서 설치 파일을 받아 직접 설치합니다.

자동 확인이 실패하면 화면에 아무것도 띄우지 않고 다음 날 다시 확인합니다.

참고

회사망에서 프록시를 쓰면 Windows의 사용자 프록시 설정(또는 HTTPS_PROXY 같은 환경 변수)을 따릅니다. 자동 구성 스크립트(PAC)로만 프록시를 정하는 회사망에서는 확인이 되지 않을 수 있으니, 그때는 Releases 페이지에서 직접 받으세요.

손으로 설치하기 ​

언제든 Releases에서 새 설치 파일 Relio_<버전>_x64-setup.exe를 받아 실행하면 덮어 설치되고 설정은 남습니다. 베타판에서 1.0.0으로 올 때는 한 번 손으로 설치해야 합니다.
