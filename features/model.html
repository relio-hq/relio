모델 메뉴 ​

모델 메뉴에서 여는 창 — 단어 사전, 그룹·글로벌 그룹, 시퀀스·트리거·테이블스페이스, 옵션, 변경 내역, 번역 관리, 테스트 데이터, 모델 특성 — 의 항목을 설명합니다. 같은 명령은 캔버스 오른쪽 클릭 › 문서 ▸에도 있습니다.

테이블·컬럼·뷰·관계처럼 캔버스의 대상을 고치는 창은 정보 창에 있습니다.

단어 사전·단어 정보 ​

  • 단어 사전 창은 단어 목록과 쓰는 컬럼 수를 보여 줍니다. 이름으로 찾기로 거르고, 쓰지 않는 단어만으로 아무 컬럼도 쓰지 않는 단어만 봅니다. 쓰지 않는 단어 모두 고르기 뒤 쓰지 않는 단어 정리로 한꺼번에 지웁니다(되돌리기 가능). 줄을 더블클릭하면 단어 정보가 열립니다.
  • 단어 정보 창은 물리명 · 논리명 · 형식 · 길이 · 소수 · enum/set 인수 · 설명을 고칩니다. 고치면 이 단어를 쓰는 모든 컬럼에 반영된다는 안내와, 쓰는 컬럼 목록(더블클릭하면 캔버스에서 그 컬럼으로 감)이 함께 보입니다.

그룹 관리·글로벌 그룹 관리 ​

그룹은 여러 테이블이 함께 쓰는 컬럼 묶음입니다(예: 등록일·수정자 같은 공통 컬럼).

  • 왼쪽 그룹 목록에서 추가 · 편집 · 삭제, 오른쪽에서 그룹명과 그룹 컬럼 표(추가·편집·삭제·순서·간편 등록)를 고친 뒤 업데이트를 누릅니다.
  • 그룹을 고치면 그 그룹을 쓰는 모든 테이블에 반영됩니다. 쓰는 테이블이 있는 그룹을 지우면 그 목록을 보여 주고 계속할지 묻습니다.
  • 글로벌 그룹에 추가는 문서의 그룹을 이 PC의 글로벌 그룹으로 복사합니다. 글로벌 그룹 관리 창의 문서에 넣기는 글로벌 그룹을 이 문서의 그룹으로 복사합니다(그 뒤로는 따로 갑니다). 이름이 겹치면 이름 바꿔 추가를 묻습니다.
  • 새 다이어그램을 만들면 글로벌 그룹 전체가 문서 그룹으로 들어갑니다.

시퀀스·트리거·테이블스페이스 ​

아웃라인에서 오른쪽 클릭이나 + 추가, 또는 모델 메뉴로 만들고, 더블클릭으로 고칩니다.

  • 시퀀스 정보 — 시퀀스명 · 스키마 · 증가 · 시작 · 최솟값 · 최댓값 · 캐시(캐시 없음) · 순환(CYCLE) · 설명. DB에 따라 데이터 형식·자릿수(DECIMAL만)·순서(ORDER)가 더해집니다. 64비트를 넘는 값도 쓸 수 있습니다. 시퀀스를 지원하지 않는 DB(MySQL·SQLite·MS Access 등)에서는 만들 수 없습니다.
  • 트리거 정보 — 트리거명 · 스키마 · SQL(CREATE TRIGGER 이름 뒤에 그대로 붙습니다) · 설명. PostgreSQL은 트리거 이름에 스키마를 붙일 수 없어 DDL에서 빼고 씁니다.
  • 테이블스페이스 정보 — 위에서 환경을 고르고 이름을 넣습니다. 아래 칸은 DB마다 다릅니다(MySQL 데이터 파일·로그 파일 그룹·스토리지 엔진, Oracle 데이터 파일·파일 크기·자동 확장, DB2 유형·페이지 크기·관리 방식·컨테이너·버퍼 풀, PostgreSQL 위치(location)·소유자, SQL Server 파일 그룹 이름·파일 경로·크기). 속성은 환경마다 따로 저장됩니다.

옵션 ​

모델 › 옵션…(또는 상태 표시줄 맨 왼쪽 대상 DB 칸)에서 문서 설정을 바꿉니다.

탭내용
데이터베이스DB, 대상 제품, 대상 버전. DB를 바꾸면 "다른 DB 전용 설정은 보존되지만 새 DB에서는 쓰이지 않습니다"를 알리고 확인을 받습니다(되돌리기 가능). 대상 버전은 이 PC에만 기억됩니다.
테이블스페이스 환경환경 목록(예: 운영 DB)과 추가 · 편집 · 삭제. 마지막 환경은 지울 수 없고, 환경을 지우면 그 환경의 테이블스페이스 속성도 지워집니다.
고급 설정새 테이블을 만들 때의 기본값(스키마·테이블스페이스, MySQL이면 스토리지 엔진·문자 집합 등).
옵션입력 포커스 이동 시 IME 모드 자동 전환 · 물리명에 쓸 수 있는 문자 검사 · 곡선(Bezier) 사용 · 검증 끄기

변경 내역 ​

모델 › 변경 내역…은 지금 다이어그램 전체의 사본을 날짜와 함께 문서 안에 남깁니다.

  • 변경 내용에 무엇을 바꿨는지 짧게 적고 추가, 고르고 업데이트 · 삭제.
  • 이 날짜 데이터 보기 — 그 시점 사본을 읽기 전용 미리보기 탭으로 엽니다.
  • 이 시점으로 되돌리기 — 문서 내용을 그 시점 사본으로 바꿉니다(되돌리기 가능).
  • 변경 내용 비교 — 고른 변경 내역(A)과 지금 문서(B)를 비교 탭으로 엽니다. Git과 합치기 › 비교 화면
  • 변경 내역마다 다이어그램 전체 사본이 들어가 파일이 커집니다. 창 아래에 개수와 대략의 크기가 나옵니다.

번역 관리 ​

모델 › 번역 관리…에서 가져오기할 때 번역 기능 사용을 켜고, 이 문서에서 쓸 번역 사전을 체크합니다(위에 있는 사전이 먼저). 사전 목록 자체는 이 PC의 앱 설정에 있고 사전 파일 추가… · 사전 관리… · 목록에서 빼기로 다룹니다. 번역 사전 파일은 UTF-8 글 파일로, 한 줄에 "원어,번역어"를 씁니다. DB에서 가져올 때 논리명을 채우는 데 쓰입니다. 환경 설정 › 번역 사전

테스트 데이터 ​

모델 › 테스트 데이터…의 왼쪽 목록에서 추가 · 편집 · 삭제 · 복사 · 출력을 합니다. 오른쪽에는 고른 데이터의 테이블명과 레코드 수가 보입니다. 출력은 고친 내용을 먼저 적용하고 테스트 데이터 내보내기 창을 엽니다.

테스트 데이터 편집 창:

  • 이름, 왼쪽 모든 테이블 ⇄ 오른쪽 데이터를 만들 테이블 (레코드 수)(추가 ▶ / ◀ 빼기).
  • 출력 순서 — 직접 입력 → 반복 입력, 또는 반복 입력 → 직접 입력.
  • 직접 입력 탭 — 표에 값을 직접 넣습니다. 붙여넣기도 됩니다.
  • 반복 입력 탭 — 레코드 수를 정하고, 컬럼 머리글을 눌러 반복 조건을 정합니다: 반복 유형(NULL · 포맷 · 열거 · 외래 키(모델에 있는 값)), 반복 수(같은 값을 몇 행씩), 포맷(%가 숫자로 바뀝니다), 시작 · 끝 · 증분, 열거 값. 미리보기에서 행을 누르면 그 행만 수정값을 지정합니다.

모델 특성 ​

모델 › 모델 특성… 또는 스탬프를 더블클릭합니다. 항목명 · 값 표(프로젝트명·모델명·버전·회사명·작성자 등)에 새 항목을 더하고 지웁니다. 작성일시·갱신일시는 저장할 때 자동으로 채워집니다. 보기 › 스탬프 표시를 켜면 캔버스에 표로 보입니다.
