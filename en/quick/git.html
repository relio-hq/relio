Work together and merge with Git ​

When several people edit .erm files kept in a Git repository, Relio saves with small diffs and merges conflicts at the model level.

Preparing the repository ​

  1. Check that "Save in Git-friendly order" is on in Tools › Settings › General (it is on by default). It keeps list order fixed so Git diffs stay small, and the files still open in ERMaster.
  2. Add one line to the repository's .gitattributes to keep line endings consistent.
*.erm text eol=lf merge=relio

merge=relio is used once you register the driver described below in "Model-level git merge".

History and comparison ​

Open File › Git history (or click the branch name in the status bar). The card at the top summarizes the change from the previous version (Tables +1 · Columns +2 ~3); click it to open the comparison view. Relio never writes anything to the repository.

Merging ​

When the same file was changed in two places, Relio merges by table, column and relationship — not by line. What each side added comes in automatically; you only choose where the same field was changed differently.

  1. Choose how to open the merge:
    • A notice that an open file was changed outside Relio → Merge…
    • A file with a Git merge conflict → File › Compare and merge › Resolve Git merge conflict…
    • Another branch → File › Compare and merge › Merge with another branch version…
  2. In the merge tab, choose 1 current · 2 incoming · 3 both for each conflict. Press F8 to go to the next conflict.
  3. When no conflicts remain, press Ctrl+Enter to apply, then save. The whole merge is undone with a single undo. If it was a Git conflict, finish with git add after saving.

Model-level git merge ​

Register the command-line relio merge as a Git merge driver, and git merge and git rebase merge .erm files at the model level automatically. The driver is part of the Git configuration and does not travel with the repository, so everyone who merges must register it on their own PC.

Warning

The installer does not add relio to the PATH. On Windows, register the full path of relio.exe in the installation folder, and always check that the path is right after registering it. The commands to register and check it are in Command line › Git merge driver.
