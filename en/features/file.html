File ​

What you do from the File menu and document tabs: new, open, save, recent files, document tabs, and automatic backup and recovery.

If you are new to Relio, start with Install and open your first file and Coming from ERMaster in Quick start.

Creating a diagram ​

File › New diagram (Ctrl+N) opens the new diagram dialog.

  • Database — Choose one of the 12 supported databases. For MySQL, also choose the Target product (MySQL or MariaDB).
  • Target version — The database version you will actually use. If you leave it unset, it shows "version not set", and design checks and DDL use the syntax available from the lowest supported version of that database (for example PostgreSQL 9.4). If unsure, leave it as is.
  • Click Create to open a new untitled tab. You choose the location and name when you save for the first time.

The target version is remembered per file on this PC, not inside the .erm file; on another PC you choose it again. To change it later, click the left end of the status bar (for example "PostgreSQL 16") to open the Database tab of the options dialog.

Opening files ​

  • Choose File › Open… (Ctrl+O) or drag an .erm file onto the window. Several files open as separate tabs.
  • Opening a file that is already open takes you to its tab.
  • Opening or dropping an .sql, .ddl, .dbml, .mmd, .mermaid or .md file does not add it right away; it opens the import dialog. Files are imported one at a time.
  • Open a sample — On the start screen or in Help › Open sample ▸, choose PostgreSQL — online bookstore (19 tables) or MySQL — users and permissions (16 tables). Samples are built into the app, so they open without the internet, and they open as a new untitled document (a copy), so your changes never touch the sample. Saving opens the Save as dialog.

Opening a damaged file ​

A damaged file is repaired as far as possible and opened. The "Opened after repairing damaged parts" window then lists the repairs in a table of Location · Entries · Original value · Interpreted value, and the same entries are kept in the problem list. Items you should look at are marked "Needs review" and shown first in yellow. Copy list copies the table. Saving stores the repaired contents.

A file that still has Git merge conflict markers (<<<<<<<) cannot be opened as is. Resolve it right away with Resolve Git merge conflict… in the notice. See Git and merging.

Recent files ​

File › Recent files ▸ shows each file name with its folder. The first nine are numbered. Files that have since disappeared are dimmed and cannot be opened. Clear list at the bottom empties the list. In the recent files list on the start screen, Remove from list removes entries one at a time.

Saving ​

  • Save (Ctrl+S) is available when something has changed. A new document or a sample copy that has never been saved opens the Save as dialog.
  • Relio writes a temporary file completely and then swaps it in for the original. Even if the app stops while saving, the original file is not damaged.
  • A changed document shows * before its name on the document tab.
  • When you close a document with unsaved changes, Relio asks Save · Don't save · Cancel.

When the file changed outside Relio ​

If another program or another person changed the file since you last opened or saved it, the "The file was changed outside Relio" window appears just before saving.

ButtonWhat it does
Merge…Opens a merge tab that combines your changes and the outside changes at the model level.
Show differencesStops saving and opens the outside file and your document in a comparison tab. You are asked again when you save.
Overwrite (discard outside changes)Discards the outside changes and overwrites the file with your document. A copy of the file before overwriting is kept in the automatic backup folder.
Save as…Saves to a different file.
CancelDoes not save.

If the file was deleted or moved, the "The file you are saving no longer exists" window lets you choose Save again here.

When you return to the window ​

If an open file is changed outside Relio, the "Another program changed the file" window appears when you come back to the window. With no unsaved changes, choose Reload or Leave as is; with unsaved changes, choose Merge…, Reload (discard my changes) or Keep my changes. If the open file was deleted, Relio tells you "The file no longer exists" and keeps the document open; saving creates the file again at that location.

Sorted saving ​

When Save in Git-friendly order is on in Tools › Settings › General (the default), lists are saved in a fixed order. Git diffs get smaller and the file still opens in ERMaster. The first save of a file after you turn this on can change many lines, so save just the reordering with File › Save again in sorted order and commit it on its own — later changes are then easier to review.

Document tabs ​

  • Each open file gets one tab. Drag tabs to reorder them.
  • Ctrl+Tab / Ctrl+Shift+Tab go to the next and previous tab.
  • A middle click on a tab closes it.
  • Right-click a tab for Close · Close other tabs · Close all · Copy path · Show in folder · Open in AI tool…. Working with AI
  • Double-click a tab to collapse the right and bottom panels at once and give the canvas more room. Canvas and palette

After a restart ​

The files that were open when you quit are reopened in the same tab order, with the tab you were viewing in front. Files that no longer exist are skipped, and if none are left you get the start screen. To turn this off, clear Reopen last session's documents at startup in Tools › Settings › General.

Automatic backup and recovery ​

  • While there are unsaved changes, Relio keeps the latest 10 copies per file in the backup folder of the settings folder at a set interval (5 minutes by default). Change the interval in Automatic backup interval (minutes) in Tools › Settings › General; 0 turns it off.
  • If Relio did not shut down normally, the "Recover unsaved documents" window appears the next time it starts. Check the document, original file and backup time, choose what to recover and click Recover. Do not recover skips it, and Open backup folder shows the files directly.
  • A recovered document opens as changed. Saving it replaces the original file. The backup files stay where they are.

Tip

Where backups and settings are kept is listed in Help and troubleshooting › Where your data is stored.
