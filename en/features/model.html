Model menu ​

The dialogs opened from the Model menu — word dictionary, groups and global groups, sequences, triggers and tablespaces, options, change history, translation management, test data and model properties. The same commands are also in canvas right-click › Document ▸.

Dialogs that edit objects on the canvas, such as tables, columns, views and relationships, are covered in Properties dialogs.

Word dictionary and word properties ​

  • The Word dictionary dialog lists the words and how many columns use each one (Used by columns). Filter with Find by name, and use Unused words only to see words no column uses. Select all unused words followed by Clean up unused words removes them all at once (can be undone). Double-click a row to open its word properties.
  • The Word properties dialog edits the physical name · logical name · type · length · scale · enum/set arguments · description. It also notes that edits apply to every column using the word, and lists those columns (double-click one to go to it on the canvas).

Manage groups and global groups ​

A group is a set of columns shared by several tables (for example common columns such as created date and modified by).

  • In the group list on the left use Add · Edit · Delete; on the right, edit the Group name and the group column table (add, edit, delete, reorder, Quick entry), then click Update.
  • Editing a group applies to every table that uses it. Deleting a group that tables use lists those tables and asks whether to continue.
  • Add to global groups copies a document group to this PC's global groups. Add to document in the Manage global groups dialog copies a global group into this document's groups (after that they are independent). If the name already exists, Relio offers Add with a new name.
  • When you create a new diagram, all global groups are added to the document's groups.

Sequences, triggers and tablespaces ​

Create them by right-clicking in the outline, with + Add, or from the Model menu, and edit them by double-clicking.

  • Sequence properties — Sequence name · Schema · Increment · Start · Min value · Max value · Cache (No cache) · Cycle (CYCLE) · Description. Depending on the database, Data type, Digits (DECIMAL only) and Order (ORDER) are added. Values beyond 64 bits are allowed. Sequences cannot be created on databases that do not support them (MySQL, SQLite, MS Access and others).
  • Trigger properties — Trigger name · Schema · SQL (appended as-is after CREATE TRIGGER name) · Description. PostgreSQL does not allow a schema on trigger names, so the schema is left out in the DDL.
  • Tablespace properties — Choose the Environment at the top and enter the Name. The fields below differ by database (MySQL data file, log file group and storage engine; Oracle data file, file size and autoextend; Db2 type, page size, management, containers and buffer pool; PostgreSQL location and owner; SQL Server file group name, file path and size). Attributes are stored separately per environment.

Options ​

Change document settings in Model › Options… (or the target database field at the left end of the status bar).

Change history ​

Model › Change history… keeps a copy of the whole current diagram, with the date, inside the document.

  • Briefly describe what changed in Changes and click Add; select an entry to Update or Delete it.
  • View the data at this date — Opens that snapshot in a read-only preview tab.
  • Restore to this point — Replaces the document contents with that snapshot (can be undone).
  • Compare changes — Opens the selected history entry (A) and the current document (B) in a comparison tab. Git and merging › Comparison view
  • Each history entry stores a copy of the whole diagram, so the file grows. The bottom of the dialog shows the number of entries and their approximate size.

Translation management ​

In Model › Translation management…, turn on Use translation when importing and check the translation dictionaries this document should use (upper ones take priority). The dictionary list itself lives in this PC's app settings and is managed with Add dictionary file… · Manage dictionaries… · Remove from list. A translation dictionary file is a UTF-8 text file with one "source,translation" pair per line. It is used to fill logical names when importing from a database. Settings › Translation dictionary

Test data ​

In the list on the left of Model › Test data…, use Add · Edit · Delete · Copy · Output. The right side shows the table names and record counts of the selected data. Output applies your edits first and then opens the test data export dialog.

The Edit test data dialog:

  • Name, with All tables on the left ⇄ Tables to generate data for (record count) on the right (Add ▶ / ◀ Remove).
  • Output order — Direct input → repeat input, or repeat input → direct input.
  • Direct input tab — Enter values directly in the grid. Pasting works too.
  • Repeat input tab — Set the record count and click a column header to set its Repeat condition: Repeat type (NULL · Format · Enumeration · Foreign key (values in the model)), Repeat count (how many rows share the same value), the format (% is replaced by a number), start · end · step, and enumerated values. Click a row in the preview to set Override values for that row only.

Model properties ​

Open Model › Model properties… or double-click the stamp. Add and delete rows in the Item name · Value table (project name, model name, version, company name, author and so on) with New item. Created and Updated are filled in automatically when you save. Turn on View › Show stamp to show them as a table on the canvas.
