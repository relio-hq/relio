On this page

Properties dialogs ​

The fields of the dialogs that edit objects on the canvas — table, column, Quick entry, index, view, relationship, note connection and image properties. Dialogs opened from the Model menu, such as the word dictionary, groups, sequences and options, are covered in Model menu.

A properties dialog opens when you double-click a node on the canvas, or select it and press Enter. Double-clicking a table or view in the outline also opens it, and double-clicking a column line under a table opens the table properties dialog with that column selected. For the steps to add columns, see Draw tables, columns and relationships in Quick start.

Table properties ​

Logical name and Physical name are at the top, with six tabs below.

TabContents
AttributesThe column table (primary key (PK) · foreign key (FK) · physical name · logical name · type · NOT NULL · UNIQUE) with Add · Edit · Delete · up and down · Quick entry. Below it: a field to choose a group, Add group items to the table, the group column table and Manage groups…
DescriptionA multi-line description used in documents and comments
Composite unique keysThe key list, UNIQUE KEY constraint name, a column checklist, and Add · Update · Delete
Constraints/optionsTable constraint, Primary key constraint name, Options (appended at the end of the table in the DDL)
IndexThe index list with Add · Edit · Delete — see "Index properties" below
Advanced settingsPer-database table options (schema, tablespace; for MySQL also storage engine, character set, collation, length when a TEXT type is a primary key and so on)
  • The fields in the column table (physical name, logical name, type, NOT NULL, UNIQUE) can be edited right in the table. Double-click a row, or select it and press Space, to open the column properties dialog.
  • If you open the dialog with a column selected on the canvas, that row is selected.
  • While you type, a line under the field points out problems (nothing is blocked). Design check and suggestions › Notes where you type
  • Columns that cannot be deleted — FK columns (delete the relationship instead) and columns referenced by other tables cannot be deleted. In that case, Delete with relationships deletes them together with the relationships; pressing OK applies it in one step, and it can be undone.
  • A composite unique key needs at least one column, and you cannot create two keys with the same column combination. Constraint names may use only letters, digits and _; leave it empty to create the key without a name (the database assigns one).

Columns that use a word — When a column uses a word, editing its names or type changes the word itself, so every column that uses the same word changes too. "Apply to n columns using this word" appears next to the field; to change only this column, click Split this column into a new word.

Suggestions while typing — Type a physical or logical name and candidates appear above the field. Pick one with ↓ and accept it with Enter. If you accepted the wrong one, click Undo fill. See Design check and suggestions for details.

Properties tab ​

This tab has UNIQUE KEY constraint name · Column constraint · Character set · Collation, and the AUTO_INCREMENT settings… button used when AUTO_INCREMENT is on. The AUTO_INCREMENT settings dialog shows only the values that database uses (start and increment for MySQL, MariaDB, SQL Server and MS Access; start for Informix; start, increment, min value, max value, cache and cycle (CYCLE) for the others). SQLite does not have this button.

Quick entry ​

Add many columns at once in a single grid. The columns are logical name · physical name · type · length · scale, and you can paste a table copied from Excel into the first cell. Add row adds more lines. Quick entry is available in the table properties, view properties and Manage groups dialogs.

Index properties ​

  • UNIQUE and FULL TEXT (MySQL and MariaDB only) checkboxes, Table name (read-only), Index name, Index type (only the methods that database supports) and Description.
  • Pick columns from All columns on the left and use Add ▶ / ◀ Remove to put them in Index columns (column name · descending) on the right; set the order with Up · Down. Descending order can be used on every supported database.
  • If you leave the index name empty and choose columns, a name is made for you.

View properties ​

The tabs are Attributes (the same column table as table properties) · SQL · Description · Advanced settings. The SQL field has line numbers and syntax coloring, and you cannot press OK while the SQL is empty. Get columns from SQL reads the SELECT list and fills the column table.

Relationship properties ​

Opens when you double-click a relationship line.

  • Constraint name — Leave it empty to create the constraint without a name (the database assigns one).
  • ON UPDATE · ON DELETE — RESTRICT · CASCADE · NO ACTION · SET NULL · SET DEFAULT. If you choose an action the current database does not support, a note next to the field says "Output as NO ACTION in this DB" or "Omitted in this DB (not output)".
  • Parent — The referenced table (read-only), the Referenced target (the primary key or a composite unique key) and Cardinality (1 · 0..1).
  • Child — Cardinality (1..n · 0..n · 1 · 0..1) and the list of FK columns.

Changing the referenced target rebuilds the child's FK columns to match the new target (one undo step). When you delete a relationship, Relio asks whether to delete its FK columns too.

Relationship using existing columns ​

Opens when you click parent → child with 1:N relationship using existing columns in the palette. Choose the Referenced target (parent primary key), then pick the Child FK columns for each target column in the table. Columns with matching names are picked in advance and marked "Picked by name". Choosing a column with a different type shows a warning.

Note connections and images ​

  • Connection properties — Opens when you double-click a note connection line. Choose a Line color or go back to the Default color.
  • Image properties — Opens when you double-click an image. Hue (°) · Saturation (%) · Brightness (%) · Opacity (0–255) and Keep aspect ratio. Changes show in the preview right away.
