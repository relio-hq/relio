Edit ​

The Edit menu: undo, cut, copy and paste, delete, find and the find and replace dialog, and Edit all properties.

The drawing steps are in Draw tables, columns and relationships in Quick start.

Edit menu ​

Menu › ItemShortcutWhat it does
Edit › UndoCtrl+ZUndoes the last edit.
Edit › RedoCtrl+Y or Ctrl+Shift+ZRedoes an undone edit.
Edit › CutCtrl+XCopies the selection and deletes it.
Edit › CopyCtrl+CCopies the selected nodes or columns.
Edit › PasteCtrl+VPastes what you copied. Available only when there is something to paste.
Edit › DeleteDeleteDeletes the selection.
Edit › Select allCtrl+ASelects every node in the current view.
Edit › FindCtrl+FOpens the find bar over the canvas. Find and highlight
Edit › Find…Ctrl+HOpens the find and replace dialog. See "Find and replace dialog" below.
Edit › Edit all properties…Edits column properties of many tables in one grid.

Items that cannot be used stay in place but are dimmed; hover over one to see why (for example "Select a node or column to use").

Undo ​

Every edit can be undone. Changing display settings in the View menu, importing from a database or another format, and applying a merge are each undone as a whole with a single undo. Things that do not change the document, such as switching category tabs or ignoring a design check finding, are not part of undo.

Cut, copy and paste ​

  • Nodes — Copy tables, views, notes, images and categories. Pasted nodes are placed at the mouse position; pasting the same thing again offsets it a little each time. Relationship lines between copied nodes come along too.
  • Into another document — You can paste into the document in another tab. Group columns from another document are added to that document's groups.
  • In a category view — Pasted nodes go into that category (the main category when you are viewing several). When pasting categories whose names already exist, a number is added.
  • Columns — Select one or more columns inside a table on the canvas and copy them; then select another table and paste, and they are added at the end of that table. Properties such as primary key (PK) and NOT NULL come along; foreign key (FK) relationships do not. If no table is selected, Relio says "Select one table to paste the columns into."

Delete ​

  • When you delete a relationship, Relio asks whether to also delete the columns used as FKs. Yes deletes the FK columns too; No keeps them as normal columns.
  • Select a column on the canvas and press Delete to delete it. FK columns and columns referenced by other tables cannot be deleted, and Relio tells you so.
  • Deleting a column also removes it from the indexes, composite unique keys and test data that used it. If there are any, Relio lists them and asks whether to continue.

Find and replace dialog ​

Edit › Find… (Ctrl+H) finds text across the whole model and replaces it in one go. The … button at the right of the find bar (its tooltip says "Find and replace…") opens the same dialog.

  • Search text — The name or text to find.
  • Replacement — The new text. Leave it empty to delete what was found.
  • Match case · Regular expression — How to search.
  • Scope tab — Check where to search.
    • All
    • Words (physical name, logical name, type, length, scale, description)
    • Tables (physical name, logical name, group name, column names, type, length, scale, default value, description)
    • Groups (group name, column names, type, length, scale, default value, description)
    • Model properties · Index · Relationship · Note
  • Results tab — Where each match was found and in which field, as a table. Click a row to select that object on the canvas.
  • Buttons Find all · Find · Replace
    • Find all searches everything in scope again, collects the results on the Results tab and highlights them on the canvas. Pressing Enter in the dialog does the same.
    • Find steps through the results on the Results tab one by one and selects each object on the canvas. After the last one it goes back to the first. If there are no results yet, it searches first and goes to the first result.
    • Replace changes only the results checked on the Results tab. A replacement is undone with a single undo.

Changing a word's values (column name, type and so on) changes every column that uses that word. After replacing, the status bar shows how many columns changed along with it.

Edit all properties ​

Edit › Edit all properties… shows the columns of every table in one grid.

  • Columns: Column logical name · Column physical name · Table logical name · Table physical name · Word · Type · Length · Scale · PK · FK · NOT NULL · UNIQUE.
  • Click a header to sort, and use the Filter (name) field to show only the rows you want.
  • You can paste several cells copied from Excel into the grid.
  • Editing a table name field applies to every row of that table. Editing a word also changes the columns that use the same word.
  • The number of edited rows is shown as "n rows changed", and OK applies everything at once (one undo step).

Right-click menus ​

Right-click the canvas for a short menu that fits the spot.

  • On a node or connection line — Properties… (Enter); Auto size, Right-angle connectors, Restore defaults and Tidy connection lines; Background color; Font and Font size; Arrange ▸ when several are selected; Cut, Copy, Paste and Delete; and Document ▸. If there are design check findings, Findings (n) ▸ is added at the bottom.
  • On an empty canvas — Add table (T) · Add note (N), Paste · Select all, Undo · Redo, Fit all, Document ▸.
  • Document ▸ — Commands that apply to the whole document: Edit all properties…, Find…, Show ▸, Import ▸, Export ▸, Page setup…, Print…, Change history…, Translation management…, Test data…, Category ▸, Manage groups…, Manage global groups…, Word dictionary…, Add trigger, sequence or tablespace…, Options… and Model properties….

If you switch Toolbar in Tools › Settings › General to ERMaster style (everything, as before), the toolbar buttons and right-click menus follow ERMaster's original layout. The menu bar stays the same.
