Categories ​

Creating category areas, the Manage categories dialog, the category tabs, viewing several categories together, and showing referencing tables.

To try it step by step, start with Split the model into categories in Quick start.

What is a category ​

A category groups the tables of a large model by business area so you can view them separately. On the canvas it is drawn as an area around its tables, and the category tabs below let you view just that category. A table can belong to several categories.

Creating an area ​

  1. Pick Category (C) in the palette.
  2. Drag on the canvas to draw the area. Nodes inside the area belong to that category.
  3. A new category is named "Category", with a number added if that name exists. Double-click the area to rename it in place.

How membership changes ​

  • In the "All" tab, when you move a node completely inside a category area, it is added to that category; when you move it completely outside, it is removed. If it overlaps the edge, its membership stays the same and the area grows to cover the node.
  • In a category tab, moving a node does not change membership; only the area grows.
  • Moving a category area also moves its nodes and the bend points of the lines between them. Resizing an area adds the nodes that are now completely inside.
  • Nodes created or pasted in a category tab go into that category (the main category when you are viewing several).

Manage categories ​

Open Model › Category › Manage categories… (also in canvas right-click › Document › Category ▸).

  • Categories to show (checked = bottom tab) — The category list. Only checked categories appear as tabs below the canvas. Moving a category up or down also changes the tab order.
  • Enter a name in Category name and click Add; for the selected category use Update · Delete.
  • Objects in the category — Check the tables, views, notes and so on that belong to the selected category.
  • The name cannot be empty, and you cannot create a duplicate name (ignoring leading and trailing spaces and case). A note under the field says "A category with the same name already exists: …" and the button is disabled. If a file made with another tool already has duplicate names, Relio opens and saves it as is and points it out in the problem list and the tab tooltip.
  • The Free layout checkbox in the dialog only preserves the value found in ERMaster files and currently has no effect (it is saved in the file only).

Category tabs ​

  • Below the canvas are "All" and one tab per category. A category tab shows only the nodes in that category. Relationship lines, find, Select all, exports and printing also follow what is currently shown.
  • Double-click a tab to rename the category.
  • View position — When you switch tabs, a tab you have already viewed during this session returns to its last position and zoom. The first time, the view moves to fit that tab's diagram only if none of its nodes are on screen (without zooming beyond 100%). Positions per tab are remembered only during this session.
  • If you delete the category you were viewing or remove it from the tabs, Relio goes to the "All" tab.

Viewing several categories together ​

From 1.0.1, Ctrl+click (⌘+click on macOS) a category tab to add or remove that category.

  • A plain click shows that tab alone. On the "All" tab, Ctrl+click works like a plain click.
  • The view shows every node visible in any of the selected categories.
  • Main category — The tab you last clicked plainly or added with Ctrl+click. Its underline is bold. Nodes created or pasted in this view go into the main category only. If you remove the main category, the most recently added of the remaining ones becomes the main one.
  • The status bar shows the order you chose them in and the main category, like Categories: Members + Orders · new nodes → Orders.
  • Adding or removing a category keeps the view where it is. You cannot remove the only remaining category.

Note

The multi-selection is remembered only during this session and is not written to the file. Only the main category is kept in the file, so it stays the same even if you also use ERMaster. Switching, adding or removing tabs is not an edit, so the document is not marked as changed.

Show referencing tables ​

Turn on Model › Category › Show referencing tables, and a category tab also shows, dimmed, the tables in other categories that this category's tables reference (point to with a foreign key). When viewing several categories, the same rule is applied for each one. This setting is saved in the document.

Find and categories ​

Finding in a category tab highlights results only within that scope. If there are matches outside it, the find bar shows "Outside this category: n" (or "Outside the selected categories: n" when viewing several), and Show in all categories searches again in the "All" tab. Find and highlight
