On this page

Settings ​

The pages of Tools › Settings…. Changes are saved immediately and apply to every document.

Choose a page on the left of the Settings dialog: General · Global groups · Translation dictionary · Excel template · DB connections · Shortcuts · Password · Design check. Settings are kept on this PC in %APPDATA%\Relio and remain after you uninstall and reinstall the app.

Updates ​

Check for new versions automatically (once a day) — When on, Relio fetches only version information from the public releases page once a day. The result of the last check is shown below it ("Last checked: … — Up to date"). Updates

AI tools ​

AI changes — Apply right away (default) · Review first. Apply right away puts AI changes straight into the open document if they do not overlap your unsaved edits (not saved, undoable); if they overlap or you are editing, you pick in a merge tab. Review first always opens a merge tab. Working with AI › Review first and the merge tab

Remembered per file on this PC ​

For each file, Relio remembers on this PC the target database version, the DB connection and the password storage method (as well as design check ignores, text export settings and so on). The table shows the file, target and connection; Delete removes one row, and Delete records of missing files cleans up records of files that no longer exist. If you move a file elsewhere, its record starts fresh.

Highlight ​

Hover and selection connection highlights, dimming the rest, dim level, highlight effect and reduce motion. Find and highlight › Highlight settings

Diagnostics ​

Keep a diagnostic log — Keeps diagnostic information such as errors and start-up time only in the settings folder on this PC (last 7 days). It is never sent over the internet and contains no file contents, names or paths. When off, no new log is written. Delete diagnostic log removes what has been kept so far. Help and troubleshooting › Diagnostic log

Global groups ​

Global groups are column groups shared by several files. They are stored in this PC's app settings and copied into a document with Add to document. This page shows the list (group name and number of columns); edit them with Manage global groups…. Model menu › Manage groups

Translation dictionary ​

The list of dictionaries used to fill logical names from physical names when importing from a database.

  • A translation dictionary file is a UTF-8 text file with one source word and its translation per line, separated by a comma (for example customer,Customer). Lines without a comma are skipped.
  • The table shows Name · Entries · File location. The built-in dictionary included in the app is always at the top.
  • New… · Add (file)… · Remove (only removes it from the list; the file is not deleted) · Up · Down · Open file.
  • Dictionaries higher in the list are used first. Choose the dictionaries for each document in Model › Translation management….

Excel template ​

  • Built-in templates — Templates included in the app (Korean — table specification and others). Use Save to file… to customize one, then Add as user template.
  • User templates — These also appear in the template list of the Excel export. They are .xlsx or .xls files with words and loops sheets and template sheets. Add… · Remove.

Export › Excel

DB connections ​

  • Saved connections — Name · Location · User of the connections saved from the database connection dialog. Rename · delete. Passwords are not stored here.
  • DB clients — Oracle Instant Client folder (the full path of the folder with oci.dll; no network paths; if empty, PATH is searched; restart the app for a change to take effect), and an ODBC driver for each of Db2, Informix and MS Access (a driver name or the full path of a .dll; empty = default name). For security, only the driver files and Oracle folder registered here are used.
  • Save with Save client settings.

Shortcuts ​

View and change every shortcut in a table (Section · Action · Key). Help › Keyboard shortcuts… also opens this page.

  • Click Change and then press the new key (Esc = cancel). The new shortcut shows in the menus right away.
  • Reset resets that row, and Clear removes its key. Reset all to defaults resets everything.
  • Keys already used by another action are flagged with "Conflicts: …".
  • The arrow keys (move by 1) · Shift+arrow keys (move by 10) · Tab (next node) · Space (hold and drag to pan) · Ctrl+mouse wheel (zoom) are Fixed keys that cannot be changed.
