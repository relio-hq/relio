On this page

Canvas and palette ​

Reading the canvas, the palette tools, selecting and moving, the Arrange menu, display settings in the View menu, zoom, pan and panels, and the outline.

For just the quick ways to get around, see Getting around the canvas in Quick start; for the drawing steps, see Draw tables, columns and relationships.

The parts of the window (menus, toolbar, palette, outline, status bar) and the word "node" are explained in Features › The window.

Reading the canvas ​

Table boxes ​

  • The table name is in the header, with one line per column below it. Primary key (PK) columns are grouped at the top and separated from the rest by a thin line.
  • The PK and FK badges at the left of a column line mark primary key and foreign key columns. A column that is both gets both badges.
  • The data type (for example varchar(100)) appears to the right of the name, and NN (NOT NULL) and UQ (UNIQUE) appear in small letters at the end of the line.
  • Auto increment (AUTO_INCREMENT) columns get a small circled + right after the name. Hover over it to see "Auto increment".
  • Group columns appear as one italic line, ≡ group name. Turn on View › Notation level › Expand groups to show the columns inside the group.
  • Views look like tables, with VIEW at the right of the header.
  • A table with no columns shows a faint "Double-click to add columns" hint (not shown in image exports or printing).
  • A new, empty document shows "Add table (T)" and how to create the first table faintly in the middle of the canvas; the hint disappears once you create a node.

Relationship line ends ​

A relationship line connects the parent (the referenced table) and the child (the table with the foreign key (FK)). The symbols at the line ends show the cardinality set in the relationship properties dialog; choose IE or IDEF1X in View › Notation ▸. Note connection lines are dashed lines without symbols.

  • With a relationship tool, click the first table and then the second, or drag from the first table and drop on the second. Clicking empty space or pressing Esc cancels. Clicking the same table twice with the 1:N relationship tool creates a self-referencing relationship.

Selecting and moving ​

  • Select — Click; Shift+click (or Ctrl+click) to add or remove; drag on empty space to select a range. Esc clears the selection.
  • Move — Drag, or use the arrow keys to move by 1 and Shift+arrow keys to move by 10. While dragging, alignment guides appear at the edges and centers of other nodes.
  • Size — Select a table or view and drag the left or right handle to change its width. You can widen it freely and narrow it down to the width that still shows all its content. The height always fits the number of columns. Notes, images and categories are resized with their handles.
  • Rename in place — F2. Edits a table's physical name or a note's text in place. The field stays open even if you switch to another program and come back, so you can keep typing.
  • Properties dialog — Double-click or Enter. Properties dialogs
  • Move focus — Tab / Shift+Tab go to the next and previous node.

Working with columns on the canvas ​

  • Click a column inside a table to select that column. Turn on View › Disable column clicks to select only whole tables.
  • Drag a selected column to reorder it within the same table, or drop it on another table to move it there. Hold Ctrl while dropping to copy instead of move.
  • Columns referenced by other tables cannot be moved. Moving an FK column to another table recreates the relationship so that table becomes the child.
  • Group columns move as a group; select a group and press Delete to remove the group from the table.
  • Drag a word or group from the outline onto a table on the canvas to add it as a column (group).

Connection lines ​

  • Drag a relationship line to add a bend point, drag a bend point to move it, and double-click a bend point to remove it.
  • Drag the end of a relationship line to another spot on the same table's border. Drop it toward the middle of the table to return it to the automatic position.
  • Relationship names are not drawn on the line. Select a relationship line to see its name in a tooltip.

Zoom and pan ​

  • Zoom in and out — Ctrl+mouse wheel (around the mouse pointer), Ctrl+= · Ctrl+- · Ctrl+0, or the zoom list on the toolbar.
  • Move the view — Hold Space and drag (release to return to your tool), the hand tool (H), drag with the middle mouse button, scroll with two fingers on a touchpad, or drag the rectangle in the minimap. While you are typing text, Space types a space.
  • Below 40% zoom, nodes are drawn as simple boxes with just their names and category names are shown large, like a map. Image exports and printing always use the normal look.
  • The zoom level and view position are saved in the document.

Panels and the start screen ​

  • Collapse and expand the right panel (outline and minimap) with Ctrl+Alt+B and the bottom panel (problem list) with Ctrl+J. The two buttons at the right end of the document tab bar and View › Panels ▸ do the same.
  • Maximize canvas — Double-click a document tab or press Ctrl+Shift+M to collapse both panels at once; do it again to return to how they were. The palette is not collapsed.
  • The collapsed state is kept the next time you start Relio.
  • Start screen — View › Start screen shows the start screen with new, open, samples and recent files. Open documents stay open; click a tab, press Esc or click Back to open documents to return. While the start screen is shown, the document menus and editing shortcuts are off.

Outline ​

  • Type in the Find by name field at the top to filter the lists.
  • Click a table or view to expand its columns (group columns show as one line with the group name) and, for tables, its indexes.
  • Double-click an item to open its dialog: word → Word properties; group → Manage groups; index, sequence, trigger or tablespace → its properties dialog; table or view → goes to that node on the canvas, selects it and opens its properties dialog; column → opens the table properties dialog with that column selected.
  • Drag words and groups onto a table on the canvas to add them as columns.
  • Table and view items show the same design check marks as the canvas at the end of the line (error ●, warning ▲, info i) — the most severe finding for that table and its columns. Hover a mark to read the findings (up to five, then "n more"); clicking it works like clicking the item. The marks follow View › Show design check marks, info marks appear only with Show info marks on canvas, ignored findings are left out, and column lines have no marks. Design check
  • Right-click for: Delete, Manage groups, Add trigger · Add sequence · Add index · Add tablespace (only those that fit the selected kind), Outline view mode (Logical name · Physical name · Logical+physical name) and Sort by (Logical name · Physical name).
  • Rows with a count of 0 are dimmed, and + Add creates the first item right away. Sequences and tablespaces can be added only when the database (version) supports them.
