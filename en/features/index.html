On this page

Features ​

Detailed reference for every menu and feature area, with all options and behavior. Pick the page for the feature you need and read just the sections you want. To follow a task in a few steps, see Quick start. Inside the app, Help › User guide (F1) has a short guide.

The window ​

  • Menus — File · Edit · View · Arrange · Model · Tools · Help. File · Edit · Canvas and palette · Model menu · Settings · Help and troubleshooting
  • Toolbar — New diagram, open and save; delete, undo and redo; zoom in, zoom out, fit and zoom level; grid and snap to grid; Export to DB; Align ▾; background color. Canvas and palette › Arrange menu
  • Palette (left) — Drawing tools. Canvas and palette › Palette tools
  • Canvas — Where you draw the diagram. Canvas and palette
  • Outline (top right) — Lists of group columns, word dictionary, tables, views, triggers, sequences, indexes and tablespaces, with counts. Canvas and palette › Outline
  • Minimap (bottom right) — The whole diagram in small. Drag the visible-area rectangle to move the view. Canvas and palette › Zoom and pan
  • Category tabs (bottom) — "All" plus one tab per category. The design check Problems: … button sits at the right end of this row. Categories
  • Problem list (bottom panel) — Design check findings, file repairs and DDL warnings. Design check and suggestions
  • Status bar (very bottom) — From the left: target database and version (click to open the options dialog), counts of tables, columns and relationships, the categories in view (for several: Categories: Members + Orders · new nodes → Orders); on the right: the Git branch name (for files in a repository — click for Git history), Disable column clicks (when on — click to turn it off), task hints, the number of selected objects, the zoom level and the Relio version.

In this guide, a node is any box placed on the canvas — a table, view, note, category area or image. Relationship lines and note connection lines are called connection lines.

Drawing and editing ​

  • File — Everything on the File menu and document tabs: new, open, save, recent files, automatic backup and opening damaged files.
  • Edit — The Edit menu: cut, copy and paste, undo, the find and replace dialog, Edit all properties and more.
  • Canvas and palette — Reading the canvas, the palette tools (select, hand, table, view, relationships, note, category, image), selecting and moving, the Arrange menu, View menu settings, zoom and pan, and the outline.
  • Properties dialogs — Table properties (columns, indexes, composite unique keys, advanced settings), column properties, Quick entry, index, view and relationship properties, and the note connection and image dialogs.
  • Model menu — Word dictionary, groups and global groups, sequences, triggers and tablespaces, options, change history, translation management, test data and model properties.
  • Categories — Creating category areas, Manage categories, the category tabs, viewing several categories together, and showing referencing tables.
  • Find and highlight — The find bar and match modes, Hangul initial-consonant search, hover and selection connection highlights, and highlight settings.
  • Design check and suggestions — Design check rules and marks, fixing and ignoring in the problem list, suggestions while typing, and relationship name matching.

Export and integration ​

  • DDL — The DDL export dialog: target database and version, what to generate, environment, encoding and line breaks, and version-specific syntax warnings.
  • Export — Excel, HTML, image, dictionary, test data, Java, DBML, Mermaid, Markdown and model JSON exports, and printing.
  • Import and other formats — Importing from SQL, DBML, Mermaid and Markdown, importing from another .erm file, where to import and what to do when names clash.
  • Databases — Database connections and the connection list, Import from DB, Export to DB, preparing Oracle and ODBC, and how passwords are stored.
  • Git and merging — Comparing two files and migration SQL, Git history, the three-way merge view, and the Git merge driver.

Settings and help ​

  • Settings — General (language, theme, backup, highlight, updates), global groups, translation dictionaries, Excel templates, DB connections, design check, shortcuts and passwords.
  • Command line — The relio export, import, diff, merge, lint and db commands and their options, exit codes, and using them in builds and CI.
  • Updates — Automatic checks for new versions, Check for updates, installing from inside Relio, and updating the portable version.
  • Help and troubleshooting — The Help menu (user guide, what's new, About Relio, open source licenses), what to do when a file does not open, Relio stops unexpectedly or a database connection fails, the diagnostic log, reporting a problem, and where your data is stored.
