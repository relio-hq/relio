Help and troubleshooting ​

The Help menu (user guide, what's new, About Relio and more); what to do when a file does not open, Relio stops unexpectedly or a database connection fails; the diagnostic log; reporting a problem; where your data is stored; and installing and uninstalling.

User guide ​

Help › User guide… (F1) opens the short guide built into the app in a window. Click a section in the table of contents on the left to jump to it. It works without the internet and follows the app's display language (English if there is no guide in that language). This site has the more detailed explanations.

What's new ​

  • The first time you run a newly installed version, the "What's new — Relio …" window opens once. Turn on Don't show again, shown only then, before closing, and it will not open by itself for later versions.
  • Open it again at any time with Help › What's new….
  • This version's changes are expanded; under Earlier versions, the last five are folded into "version · one-line summary" lines that expand when clicked. Show full change history expands the remaining versions inside the app (nothing is opened on the internet).
  • The bottom of the window shows the current version, an Open releases page link and a Check for updates button.

About Relio ​

Help › About Relio shows the version, an Open releases page link, a Check for updates button and a line with the automatic update check status ("On", "Off" or "Not set (off)"). Click Open source licenses to read the full license texts of the open source components Relio uses in a read-only window.

Common problems ​

SymptomWhat to do
A file does not openThe error window shows the line and column. Files with an abnormal structure, such as extremely deep nesting, are refused for safety. If the file was repaired while opening, review the repairs. File › Opening a damaged file
Relio says another program changed the fileWhen you return to the window, Relio asks whether to reload. If you have unsaved changes, choose Merge… (combine your changes with the outside changes at the model level) · Reload (discard my changes) · Keep my changes.
A file does not open after a Git mergeIf it still has conflict markers (<<<<<<<), the notice takes you straight to Resolve Git merge conflict…. For a file broken by a line-based "accept both", the repairs show which tables and columns were affected, and Redo the merge at the model level merges it again. Git and merging
Relio stopped unexpectedlyWhen you start it again, it offers to recover from the automatic backup. Backups are also in the backup folder of the settings folder. File › Automatic backup and recovery
Cannot connect to a databaseCheck the server, port, database name and firewall. For servers with a self-signed certificate, turn on Trust server certificate (self-signed) under Advanced ▾ in the connection dialog. For Oracle, check that the Instant Client folder is registered; for Db2, Informix and MS Access, check that the ODBC driver is installed. Databases

The new version check does not workUpdates › When the check fails

Types look empty in ERMaster ​

Columns that use a type only Relio has (for example json, jsonb or vector) show an empty type field when opened in ERMaster. In the type list of the column properties dialog, such types carry a note saying they look empty in ERMaster, so you know in advance. They work fine in Relio, but if your team mixes ERMaster and Relio, choose types that both tools have.

Diagnostic log ​

  • Relio keeps diagnostic information such as errors and start-up time only in the logs folder of its settings folder on this PC (last 7 days, 5 MB in total).
  • It is never sent over the internet and contains no file contents, table names, paths or user names.
  • If Relio closed unexpectedly, a bar at the bottom of the window tells you once the next time it starts, with a shortcut to Report a problem….
  • If you do not want a log, turn off Keep a diagnostic log in Tools › Settings › General › Diagnostics and remove existing files with Delete diagnostic log.

Reporting a problem ​

Open Help › Report a problem…. The window shows the Relio version and Windows version, and fields to fill in (Steps to reproduce · Expected behavior · Actual behavior).

ButtonWhat it does
Report on GitHubOpens the GitHub new issue page in your default browser. The version information is filled into the form automatically (a GitHub account is needed).
Copy report detailsWhen you cannot use GitHub, copies the same version information and fields so you can paste them into an email or chat.
Save anonymized copy…Saves a copy of the open document with names, descriptions, notes, default values and so on removed (only the structure remains). The current document is not changed.
Open diagnostic log folder · Copy recent logSee the diagnostic log files, or copy the last 200 lines to attach to your report.
  • Either way, file contents, paths and user names are not included.
  • Please first check whether the same problem happens with a sample (Help › Open sample ▸). If it reproduces with a sample, we can check it quickly.

Warning

Do not upload company .erm files or screenshots. The table structure itself is company information. If the problem is caused by a file, attach a copy made with Save anonymized copy….

Where your data is stored ​

WhatWhere
ModelsThe .erm files you save
App settings · connection list · recent files · per-file records (DDL target version · text export settings · design check ignores and so on)%APPDATA%\Relio
Automatic backups (latest 10 per file)%APPDATA%\Relio\backup
Diagnostic log (last 7 days)%APPDATA%\Relio\logs
Database passwordsWindows Credential Manager (entries starting with relio:) — inside the .erm if turned on per file

Apart from checking for new versions (only when you turn it on or check yourself), Relio never connects to the internet on its own, and never sends usage data, error reports or file contents anywhere.

Installing and uninstalling ​

  • Install — Run the installer (Relio_<version>_x64-setup.exe). It installs for the current user only, without administrator rights. You choose whether to add a desktop shortcut during setup.
  • Portable version — Unzip Relio_<version>_x64_portable.zip and run relio.exe. It uses the same settings folder as the installed version.
  • Supported — Windows 10 and 11 (64-bit). Microsoft Edge WebView2, which Relio uses to display its interface, is built into Windows 10 and 11.
  • Update — Install from inside Relio, or simply run a new installer; it installs over the old version and keeps your settings. Updates
  • Uninstall — Remove Relio in Windows Settings › Apps. Settings, the connection list and backups (%APPDATA%\Relio) remain and are used again if you reinstall.
  • Remove everything — After uninstalling, delete the %APPDATA%\Relio folder and the Windows Credential Manager entries starting with relio: (you can also delete them first in Tools › Settings › Password).
