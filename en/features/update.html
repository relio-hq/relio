Updates ​

Automatic checks for new versions, Check for updates, downloading and installing a new version from inside Relio, and updating the portable version. Available from 1.0.0.

How to turn on notices the first time you run Relio is in Install and open your first file in Quick start.

Turning automatic checks on and off ​

  • The first time you run Relio, a bar at the bottom of the window says "Want to know when a new version is out? Relio checks the public releases page once a day for version information only." Yes, let me know turns checks on and No thanks turns them off. If you close the bar without answering, the setting stays undecided (treated as off).
  • To change it later, turn Check for new versions automatically (once a day) on or off in Tools › Settings › General. Turning it on checks once right away.
  • When on, Relio checks in the background shortly after starting, and only if a day has passed since the last check. If a check fails, it is not retried; Relio checks again the next day.
  • The result of the last check is shown below the setting ("Last checked: … — Up to date" / "… — New version …" / "… — Couldn't check").

What is sent and received ​

A check only downloads a version information file from a fixed address on the public releases page. Relio does not send its version, information about your PC or anything else. GitHub can, however, see the IP address that connects. Check results are kept only in this PC's app settings.

Checking manually ​

Help › Check for updates… checks right away, regardless of the automatic check setting. The Check for updates buttons in the About Relio and What's new windows do the same. The result appears in a small window.

  • If you are up to date: "You're on the latest version (…)."
  • If a new version is available: the notice described below.
  • If the check fails: the reason and an Open releases page link (see "When the check fails" below).

New version notice ​

When the automatic check finds a new version, a "Relio … is available" notice appears at the bottom right of the window. Click Details to open the notice window.

  • The title "A new version is available", Current … → New …, the release date, a summary of changes and a Show full change history link.
  • Install now — Downloads and installs it (see below).
  • Later — Closes the window. You are reminded at the next automatic check.
  • Skip this version — You are not reminded about this version again; you will be when a newer one comes out. When you check manually, a skipped version is still shown, with "You chose to skip this version".

Installing ​

  1. Click Install now and a progress bar ("Downloading… received / total") appears in the same window. You can Cancel, and you can keep working in the meantime.
  2. The signature of the downloaded file is checked. If it does not match, nothing is installed.
  3. If there are unsaved documents, Relio says "Unsaved documents: n. Relio must close to install." and asks Save all and install · Install without saving · Cancel.
  4. After "Starting the installer. Relio will reopen when it's done.", Relio closes, the installer runs, and Relio opens again.

If a task such as an export is in progress, you can install after it finishes. Your settings, connection list and backups are kept.

Portable version ​

The portable version (unzipped from Relio_<version>_x64_portable.zip) checks and notifies you the same way. It does not install itself, though: the notice window says "The portable version can't update itself. Download the new zip and replace it." with an Open download page button. Download the new zip, unzip it and use its relio.exe. It uses the same settings folder as the installed version, so your settings carry over.

When the check fails ​

MessageWhat to do
Couldn't reach the update server. Check your internet connection or company network settings.Check your internet connection or proxy, or download from the releases page yourself.
Couldn't read the update information. Try again later or download it from the releases page.Check again a little later.
The downloaded file's signature didn't match, so it wasn't installed. …The file may be damaged or altered. Download it from the releases page yourself.
Couldn't download the new version (…).Click Try again or check your disk space.
Installation failed. Relio is unchanged. …Download the installer from the releases page and install it yourself.

If an automatic check fails, nothing is shown on screen; Relio checks again the next day.

Note

On company networks that use a proxy, Relio follows the Windows user proxy settings (or environment variables such as HTTPS_PROXY). On networks that set the proxy only through an automatic configuration script (PAC), the check may not work; in that case, download from the releases page yourself.

Installing manually ​

At any time, you can download the new installer Relio_<version>_x64-setup.exe from Releases and run it; it installs over the old version and keeps your settings. Moving from a beta version to 1.0.0 requires one manual installation.
