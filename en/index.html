THE FILE IS THE MODEL

No server, no account —
your ERD is just a file

Because the model is a file, you can commit it, change it on a branch, review it and merge it. The ERMaster files you already have work as they are.

01

Same format as ERMaster

An .erm opened and saved in Relio still opens in ERMaster. Teams can mix both tools, and simply opening and saving a file never changes it.

Coming from ERMaster →
02

Saved with Git in mind

Lists are saved in a fixed order (on by default), so each commit changes only a few lines. Branch, compare history, review and merge — the Git workflow you already know.

Working together with Git →
03

Stays on your PC

No sign-up and no login. Apart from checking for new versions (only when you turn it on or check yourself), Relio never goes online on its own and never sends usage data or file contents anywhere.

FEATURES

More than a drawing tool

Check, find, compare and merge — all in one tool. Every picture is a real screenshot of the app; the model is a made-up example.

BUILT FOR GIT

Two people edit the same file? Relio merges the model

Merge conflicts and files changed elsewhere are merged by table, column and field — not by line. What each side added comes in as is; you only decide where the same field was changed differently. The result is always a valid .erm.

  • Compare two models and browse commit history
  • Generate migration SQL (ALTER)
  • Use relio merge as a Git merge driver
Learn more →

DESIGN CHECK

Catches problems while you draw

Fifteen rules — no primary key, foreign key without an index, reserved words as names and more — run after every edit. Fix a finding with one click in the problem list, or ignore it. Nothing is ever blocked.

  • Errors and warnings on the canvas and status bar
  • Info findings folded into one line per rule
  • The same checks in CI with relio lint
Learn more →

FIND AND HIGHLIGHT

Find anything in a big model, fast

Type in the find bar and every matching table, column, relationship and note lights up while the rest is dimmed, so you can see where things are at a glance. It even supports Hangul initial-consonant search for Korean names.

  • Enter or F3 to step through results
  • Contains, Word and Exact match modes
  • Hover to bring connected objects forward
Learn more →

DDL AND DATABASES

DDL for 12 databases, version-aware

PostgreSQL, MySQL, MariaDB, Oracle, SQL Server, Db2, H2, HSQLDB, SQLite, Informix, MS Access and standard SQL. Pick the target database and version and the preview updates right away.

  • Import from and export to databases
  • Built-in drivers for PostgreSQL, MySQL, MariaDB, SQL Server and SQLite
  • Excel documents, HTML, images and Markdown

COMMAND LINE AND CI

What you do in the app,
your build can do too

Export, import, compare, merge, check and talk to databases with a single command. Results come back as exit codes, so CI can require a clean design check before anything is merged.

  • export · import · diff · merge · lint · db
  • Register relio merge as a Git merge driver
  • Migration SQL (ALTER) from the command line
Learn more →

AND MORE

What an everyday tool needs

Other formats

Build a model from SQL (pg_dump, mysqldump), DBML, Mermaid or Markdown, and export to DBML, Mermaid and JSON.

Documentation exports

Excel table documents (ERMaster templates work too), HTML, images, Markdown, Java and test data.

Safe by design

Every edit can be undone and automatic backups let you recover. Even a damaged file is repaired as far as possible and opened.
