Git으로 함께 쓰기·합치기 ​

.erm 파일을 Git 저장소에 두고 여럿이 고칠 때, Relio는 차이를 작게 저장하고 충돌을 모델 단위로 합칩니다.

저장소 준비 ​

  1. 도구 › 환경 설정 › 일반의 **"Git에 맞춰 정렬해 저장"**이 켜져 있는지 확인합니다(기본 켜짐). 목록 순서를 고정해 Git 차이를 작게 만들고, ERMaster에서도 그대로 열립니다.
  2. 저장소의 .gitattributes에 한 줄을 넣어 줄 끝을 맞춥니다.
*.erm text eol=lf merge=relio

merge=relio는 아래 "git merge도 모델 단위로"를 등록했을 때 쓰입니다.

이력 보기와 비교 ​

파일 › Git 이력(또는 상태 표시줄의 브랜치 이름)을 엽니다. 맨 위 카드가 직전 버전과 비교한 요약(테이블 +1 · 컬럼 +2 ~3)을 보여 주고, 누르면 비교 화면이 열립니다. Relio는 저장소에 아무것도 쓰지 않습니다.

합치기 ​

같은 파일을 두 곳에서 고쳤을 때 줄이 아니라 테이블·컬럼·관계 단위로 합칩니다. 양쪽이 각자 더한 것은 저절로 들어오고, 같은 칸을 다르게 고친 것만 고르면 됩니다.

  1. 여는 길을 고릅니다.
    • 열어 둔 파일이 바깥에서 바뀌었다는 알림 → 합치기…
    • Git 병합 충돌이 난 파일 → 파일 › 비교·병합 › Git 병합 충돌 풀기…
    • 다른 브랜치와 → 파일 › 비교·병합 › 다른 브랜치 버전과 합치기…
  2. 합치기 탭에서 충돌마다 1 내 쪽 · 2 바깥 쪽 · 3 둘 다를 고릅니다. F8로 다음 충돌로 갑니다.
  3. 남은 충돌이 0이면 Ctrl+Enter로 적용하고 저장합니다. 합친 결과 전체가 되돌리기 한 번으로 돌아갑니다. Git 충돌이었다면 저장한 뒤 git add로 마칩니다.

git merge도 모델 단위로 ​

명령줄 relio merge를 Git merge driver로 등록하면 git merge·git rebase가 .erm을 자동으로 모델 단위로 합칩니다. 등록은 Git 설정이라 저장소에 따라가지 않으므로, 병합하는 사람마다 자기 PC에 등록해야 합니다.

주의

설치 파일은 relio를 PATH에 넣지 않습니다. Windows에서는 설치 폴더의 relio.exe 전체 경로로 등록하고, 등록한 뒤 경로가 맞는지 꼭 확인하세요. 등록 명령과 확인 방법은 명령줄 › Git merge driver에 있습니다.
